# 数据查询与报表细节问题评估与落地方案

## 1. 文档定位

本文承接 `docs/design-v1/04-数据查询与报表系统设计.md`、`docs/design-v1/07A-问数闭环与测试集验收细化设计.md` 和 inbox 文档《数据查询与报表细节问题和解决方案评估.txt》。

本模块本质是 AI 广告数据 Copilot 的数据语义层、报表生命周期和数据可信度治理。

## 2. 默认时间规则

不能全系统统一默认“昨天”或“近 7 天”，必须按任务类型处理。

| 用户任务 | 默认时间 | 说明 |
|---|---|---|
| 查消耗、点击、激活 | 昨天自然日 | 广告日报默认语义，避免当天回传不完整 |
| 趋势分析 | 最近 7 天 | 趋势需要多个数据点 |
| D1 ROAS | 最近 7 天 | 兼顾成熟度和趋势 |
| D7 ROAS | 最近 14 天 | 等待窗口成熟 |
| D30 ROAS | 最近 45 天 | 等待窗口成熟 |
| 异常/告警/盯盘 | 今天实时 | 用户通常关注当前问题 |
| 对比分析 | 当前周期 vs 上一周期 | 周期必须可解析 |

必须追问：

- “ROI 怎么样”但未说明 D1/D7/D30。
- “最近效果不太行”。
- “看看回收”但内部口径无法唯一映射。
- “分析一下”但没有指标和时间。
- 复盘、汇报类问题且时间影响结论。

## 3. 指标歧义治理

不允许大模型自由猜指标，必须通过 Metric Registry 或受控术语词典解析。

示例：

```json
{
  "metric_alias": "成本",
  "possible_metrics": [
    "激活成本(CPI)",
    "注册成本(CPR)",
    "付费成本(CPA)",
    "广告消耗(Spend)"
  ],
  "default_by_scene": {
    "买量优化": "CPI",
    "投放日报": "Spend",
    "付费分析": "CPA"
  }
}
```

解析优先级：

1. 当前句子明确指标。
2. 当前页面上下文。
3. 用户历史偏好。
4. 当前任务场景。
5. 系统默认。

如果仍不唯一，必须追问。

## 4. 空结果解释

查询结果为空不能直接回答“没有数据”。必须通过 Empty Result Resolver 区分：

| 类型 | 含义 | 用户展示 |
|---|---|---|
| true_zero | 真实为 0 | B 项目昨天消耗为 0 |
| data_delay | 数据延迟 | 当前数据尚未完整回传 |
| no_permission | 权限不足 | 你当前没有查看该项目数据的权限 |
| interface_failed | 接口失败 | 接口调用失败，已生成或建议生成 Case |
| filter_too_strict | 条件过严 | 当前筛选条件无结果，可放宽 |
| etl_not_ready | 数据未产出 | 今日明细数据仍在计算中 |

系统应检查数据源接口、ETL 状态、分区状态、回传延迟、权限过滤、SQL 返回、筛选条件。

## 5. 报表对象模型

四层对象必须区分：

| 对象 | 含义 | 是否保存数据 |
|---|---|---|
| Report Template | 模板，保存布局、指标、图表、默认时间、过滤规则 | 否 |
| Report Draft | 用户临时编辑状态 | 默认不保存 |
| Report Snapshot | 正式固化报表 | 是 |
| Scheduled Report Job | 定时报表任务定义 | 否，每次执行生成 Snapshot |

用户已确认：报表草稿默认不保存。查询结果只有用户保存后才写入资产，自动化和定时报表产物默认写入资产。

## 6. 用户修改后保存

用户修改查询结果后再保存，必须同时保存：

- 原始查询结果。
- 用户加工视图。
- 加工操作链。
- 快照时间。

推荐结构：

```json
{
  "raw_query_result": {},
  "transformations": ["过滤低消耗计划", "按媒体聚合", "新增ROI列"],
  "final_view": {},
  "snapshot_time": "2026-05-26 09:00:00"
}
```

保存“视图”不等于只保存静态表，而是保存可复现的数据加工过程。

## 7. 定时报表可靠性

创建定时报表时必须确认数据延迟策略。

失败策略：

| 连续失败次数 | 行为 |
|---:|---|
| 1 | 自动重试 |
| 2 | 降级重试 |
| 3 | 通知用户 |
| 5 | 自动暂停 |
| 7 | 标记异常任务 |

权限失败立即通知，因为无法自动恢复。普通接口失败不要每次都通知，避免报警轰炸。

## 8. 验收规则

- “查消耗”未说时间时默认昨天，并在回复中明示。
- “ROI/回收”歧义时追问，不能猜。
- 空结果必须给出分类，不得只写“无数据”。
- 报表草稿默认不进入资产。
- 用户保存后，资产包含原始结果、加工链和最终视图。
- 定时报表创建时必须确认数据延迟策略。
- 自动化和定时报表产物默认进入资产。
