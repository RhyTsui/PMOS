# 个人记忆与知识库细节问题评估与落地方案

## 1. 文档定位

本文承接 `docs/design-v1/03-个人记忆与知识库用户隔离系统设计.md`，补齐个人记忆、个人知识库、通用知识库、受控术语词典和项目权限之间的边界。

核心结论：

个人记忆不等于个人知识库，不等于会话上下文。

## 2. 四类信息分层

| 类型 | 保存什么 | 保存方式 | 用途 |
|---|---|---|---|
| 会话上下文 | 当前任务临时信息、项目、包、指标、附件、证据 | 自动，随会话或任务存在 | 支撑本轮和当前任务连续对话 |
| 个人记忆 | 用户偏好、常用项目、常用指标口径、常用日报格式 | 自动提取 + 用户可管理 | 降低重复确认，提升个性化 |
| 个人知识库 | 用户主动沉淀的问答、经验、AI 回复、案例、文档 | 手动保存为主 | 形成用户私有经验资产 |
| 受控术语词典 | 公司级标准名词、指标口径、项目/媒体/包标准名称 | 管理后台维护 | 统一口径和意图理解 |

## 3. 自动进入个人记忆的内容

允许自动保存：

- 用户偏好：默认项目、默认媒体、默认日报格式、常用时间范围。
- 用户常用业务对象：经常查询的项目、包、指标。
- 用户表达习惯：例如“消耗”默认指广告消耗，“回收”在该用户语境下常指 D7 ROAS。
- 用户确认过的纠错结果：例如“我说的 B 项目一般指 B-海外版”。

不允许自动保存：

- 原始完整输入。
- 整段会话。
- 项目敏感数据。
- 查询结果里的真实消耗、ROI、成本、收入。
- AI 的业务判断结论。

这些敏感内容只能存在于会话上下文、证据资产或用户手动保存的知识库条目中，并受项目权限过滤。

## 4. 个人记忆纠错

纠错优先级：

1. 用户本轮显式纠正。
2. 用户手动保存的知识。
3. 个人记忆。
4. 历史会话摘要。

处理规则：

- 个人记忆错误：用户可在“我的记忆”里删除、禁用、编辑。
- 当前 TaskContext 错误：用户纠正后覆盖当前任务上下文，并重跑受影响任务。
- 知识库内容错误：用户手动编辑知识库条目，保留版本记录。

系统不能用新的个人记忆静默覆盖已确认的当前任务事实。

## 5. 项目权限冲突

个人记忆可以保留弱记忆，但不能突破当前权限。

允许记住：

- 用户常看 B 项目的日报。
- 用户习惯按媒体维度看某类报表。

不允许记住：

- B 项目昨天消耗 80 万。
- D7 ROAS 为 12%。
- 某包付费率异常。

如果用户当前没有 B 项目权限，系统可以提示“你之前使用过 B 项目，但当前无权限查看该项目数据”，不能展示历史敏感事实。

权限链路必须是：

```text
用户身份 -> ABAC 策略 -> Agent 权限限制 -> Tool 权限控制 -> 知识访问过滤 -> 输出审计
```

## 6. 个人知识库 Key

系统需要提供用户配置个人知识库 Key 的功能。用户入口在左下角弹窗，与资产、自动化入口独立。

个人知识库状态：

| 状态 | 用户可见文案 |
|---|---|
| 正常同步 | 个人知识库同步正常 |
| 仅本地可用 | 当前仅使用本地记忆和本地缓存内容 |
| 同步失败 | 个人知识库同步异常，系统将重试 |
| 等待重试 | 同步等待重试 |
| 管理员处理 | 同步异常已进入管理员处理 |

不展示 key、token、接口错误码或底层技术细节。

## 7. 知识融合优先级

当受控术语词典、个人知识库、通用知识库同时命中时，按以下原则融合：

1. 受控术语词典决定名词、指标、项目、包、媒体的标准解释。
2. 权限过滤后的项目/业务数据决定事实数据。
3. 个人知识库补充用户经验、历史问法、沉淀案例。
4. 通用知识库补充产品说明、操作手册、业务规则。
5. 通用大模型知识只做兜底，必须标注非系统知识。

一句话规则：术语词典定口径，权限数据定事实，个人知识库定偏好，通用知识库定流程，大模型只做语言组织和推理补充。

## 8. 保存 AI 回复到知识库

用户手动保存 AI 回复到知识库时，应保存分级结构：

```json
{
  "question": "用户原始问题",
  "answer": "AI回复内容",
  "project_ref": "项目ID/项目名",
  "task_type": "归因诊断/日报/问题排查",
  "evidence": [
    {
      "type": "数据表/截图/文档/接口结果",
      "source": "BI/MCP/知识库/附件",
      "time_range": "2026-05-25",
      "permission_snapshot": "保存时权限"
    }
  ],
  "visibility": "private",
  "sensitivity_level": "normal/confidential/restricted",
  "version": 1
}
```

再次检索时仍要按当前权限过滤，不能因为用户曾经保存过就绕过项目权限。

## 9. 验收规则

- 未配置个人知识库 Key 时，个人记忆不能显示为已远端同步。
- 通用知识库只读，个人记忆写入用户个人作用域。
- 自动记忆不保存敏感项目数据和 AI 业务判断结论。
- 用户可删除、禁用、编辑个人记忆。
- 受控术语词典命中时优先统一口径。
- 权限撤销后，个人记忆和知识库命中不能泄露失权项目数据。
