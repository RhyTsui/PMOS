# 需求覆盖矩阵与待澄清事项

## 1. 文档目的

本文件用于回看本轮讨论中已经确认的关键结论，确保正式 PRD、系统设计和工程实施清单不会再次遗漏。

状态定义：

- `已纳入`：已写入本次文档包。
- `需系统设计展开`：PRD 已定义方向，但系统设计阶段需要继续细化。
- `后续阶段`：不进入一期 P0。

## 8. 仍需后续展开的事项

以下内容不影响 V2.2 主 PRD 成立，但进入系统设计或后续需求阶段：

1. 自动学习规则的定义：建议不要定义为裸 Agent 自学习，优先定义为规则沉淀、失败案例沉淀、路由样本沉淀和评测样本沉淀。
2. 市场情报二期的外部来源范围、引用规范和资产沉淀规则。
3. 预测三期的模型责任边界、置信度展示和风险提示。
4. 受控自动化执行四期的审批策略、风险分级和回滚机制。
5. 具体 MCP / 智投接口字段需要研发与接口方在系统设计阶段确认。
6. 第三阶段系统设计开始前，需要按 `18-意图路由知识库与能力闭环设计准入评估.md` 核对每个 P0 / P1 意图的能力注册、输入输出、错误码、证据、Trace 和评测样本。
