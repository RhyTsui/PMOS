# 小乔智投 PRD V2.2 文档包

本文档包是小乔智投当前阶段的核心产品定义。它承接前期战略、PRD V2、PRD V2.1、多角色评审、当前系统实现盘点，以及本轮对“Chat / Workflow / Skill / MCP / 智投接口”责任拆分的确认。

V2.2 的核心修订不是新增一组功能清单，而是纠正一个关键方向：小乔智投不能把业务执行能力写进 Chat 层，不能靠前台话术制造假闭环。正确产品形态是：

- Chat 负责意图、对话、上下文、追问、权限预检、能力绑定、结果解释、证据呈现、资产与 Case 入口。
- Workflow 负责多步骤流程、状态流转、异步等待、失败分支、证据聚合、业务结论生成。
- Skill 负责业务能力封装，提供稳定入参、出参、错误码、证据和下一步建议。
- MCP / 智投系统接口负责真实数据、真实检查、真实动作和原始证据。
- 连弩平台负责 Trace、评测、回放和证据规则，小乔不重建评测平台，只发送结构化记录。

## 本文档包的约束

1. 当前已实现能力必须被保留、纳入和纠偏，不允许在新 PRD 中被遗漏。
2. 所有需求必须同时写清用户需求和产品需求，不能停在产品机制层。
3. 每个业务闭环必须能追溯到真实 Workflow / Skill / MCP / 智投接口，未接入时不能写成已完成。
4. 所有关键结论必须有 Evidence、Trace、权限上下文和下一步建议。
5. 一期优先完成可信服务闭环，不承诺完整数字优化师、市场情报、预测和受控自动投放执行。
