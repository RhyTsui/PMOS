# 我的资产与自动化任务中心 PRD

## 1. 我的资产定位

我的资产是用户可复用结果的沉淀中心，不是所有过程数据的堆积池。

它承接用户明确保存的结果、系统自动化产物、包交付记录、Case 和证据集合。资产必须可追溯来源、项目、证据和后续动作。

我的资产、个人记忆和个人知识库不是同一个对象。资产是正式业务产物；个人记忆是按用户隔离的上下文和偏好沉淀；个人知识库是用户配置 key 后可同步和检索的外部知识空间。详细见 `19-个人记忆与知识库用户隔离需求设计.md`。

## 2. 资产类型

一期资产类型包括：

- 查询结果。
- 报表。
- 报表模板。
- 定时报表产物。
- 包交付记录。
- 异常 Case。
- 需求 Case。
- Evidence bundle。
- 需求记录。

## 3. 写入规则

| 来源 | 是否默认写入资产 | 说明 |
|---|---|---|
| 一次性查询结果 | 否 | 用户点击保存后写入 |
| 报表草稿 | 否 | 草稿是临时工作态 |
| 用户保存报表 | 是 | 成为报表资产 |
| 报表模板 | 是 | 可跨项目复用 |
| 定时报表产物 | 是 | 自动产物默认入资产 |
| 自动化任务产物 | 是 | 默认入资产 |
| 包交付记录 | 是 | 包状态、结论、证据可追溯 |
| 联调失败 Case | 是 | 或可在资产中引用 |
| 异常排查 Case | 是 | 或可在资产中引用 |
| 需求协同 Case | 是 | 或可在资产中引用 |

## 4. 项目权限

资产必须支持：

- 项目字段。
- 项目查看。
- 项目筛选。
- 动态权限过滤。
- 部分隐藏状态。

如果用户失去某项目权限：

- 单项目资产不可见。
- 跨项目资产中该项目部分隐藏或脱敏。
- Evidence 中无权限项目内容隐藏。
- Trace 和审计保持完整。

## 5. 资产详情

资产详情应展示：

- 标题。
- 类型。
- 项目。
- 来源。
- 创建人。
- 创建时间。
- 来源对话。
- 来源 Workflow。
- Evidence。
- 可执行下一步。

资产不是静态归档，应该能继续发起：

- 再查询。
- 生成报表。
- 创建定时报表。
- 查看包历史。
- 打开 Case。
- 继续对话。

## 6. 自动化任务中心定位

一期自动化任务中心优先服务低风险、可审计、可重复的任务，P0 是定时报表。

不在一期承诺高风险自动投放执行。

## 7. 自动化任务类型

一期 P0：

- 定时报表。

后续扩展：

- 定时触发 Skill。
- 周期性包状态巡检。
- 周期性异常巡检。
- 小闪通知。
- 定期生成 Evidence bundle。

## 8. 自动化任务项目规则

自动化任务可以多项目，但必须：

- 创建时选择项目。
- 编辑时可调整项目。
- 列表展示项目。
- 支持项目筛选。
- 运行时校验项目权限。
- 产物进入资产后继续按项目权限过滤。

包交付类任务除外，包交付必须单项目。

## 9. 定时报表任务展示

定时报表任务列表应展示：

- 任务名称。
- 项目。
- 报表模板。
- 周期。
- 执行时间。
- 数据延迟策略。
- 最近运行时间。
- 最近运行状态。
- 最近产物。
- 失败原因。

创建定时报表时，如果用户没有确认数据延迟策略，任务不能启用。
