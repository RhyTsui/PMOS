总览结论

主链状态

Chat 主链已经从“单一报表链”调整为“request understanding + capability orchestration + report runtime + presentation”。

P0.6 位置

主要风险

clarification 与 capability blocking 的边界、`/api/chat` 的超大 handler、prompt / control plane 的多源真源仍是高风险项。

快速结论

  • 通用 Chat 仍存在向 Report Query 退化的历史风险，但 P0.6 已在收缩前置阻断。
  • Query Contract 前置阻断问题已明显减弱，但尚未完全收口。
  • Capability Discovery 已前移到 preflight 语义，但与参数表单仍存在边界耦合风险。
  • SemanticResultContract 和 RuntimeDisplayProtocol 已作为主协议生效，不应再被路由层劫持。
  • 后台已有入口，但控制面仍不是单一 source-of-truth。
