# 会话沉淀：个人知识库内置授权

- 日期：2026-06-01
- 范围：小乔智投个人知识库授权、个人中心弹窗、管理中心配置
- 状态：已实现并重启 8002 服务

## 需求结论

个人中心不再让用户手动录入 Dataki KEY。管理中心配置 Dataki 超级管理员账号密码后，用户首次登录时后端查询该用户的个人知识库 KEY，并写入用户信息表。KEY 不会每天变化，后续登录和同步直接读取用户信息表。

## 已落地

- 用户信息表增加 Dataki KEY、租户、状态、解析时间和错误信息字段。
- 登录链路在首次登录或用户表无 KEY 时解析个人知识库授权。
- 个人记忆同步只读取用户信息表中的 KEY；没有 KEY 时保留本地待同步状态。
- 个人中心弹窗只展示“已内置个人知识库，访问地址：dataki.dobest.com”，按钮新标签页打开。
- 管理中心支持配置 Dataki 管理员账号、密码和地址，并可测试授权。
- 用户管理支持查看个人知识库授权状态并手动刷新授权。

## 验证

- `npm.cmd run validate:ad-ui` 通过。
- 服务已重启，`http://127.0.0.1:8002` 正常响应并跳转登录页。

## 注意

- 明文 Dataki KEY 只保存在后端用户信息表，不通过用户管理接口返回。
- 管理操作日志只记录脱敏状态，不记录明文 KEY 或管理员密码。
