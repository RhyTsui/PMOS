智投 Chat 主色与辅助色局部定义

该色板只约束智投 Chat 当前对话工作台，不替换 PMOS 全局规范，也不触发全局换色。

主色
#2E75FE
主操作、发送按钮、输入框焦点、可执行建议高亮。
成功色
#00B368
复制成功、执行完成、校验通过。
警示色
#D49600
待确认、可继续但存在条件限制。
危险色
#E0204A
失败、阻断、删除或不可逆风险。
信息色
#6B46E0
信息提示、需求/知识/辅助说明。
文字中性色
#1F1F1F / #4D4D4D / #7A7F87
标题、正文、说明、meta 信息。
背景与卡片
#F8FAFC / #FFFFFF
页面背景、卡片承载，不制造大面积色块。
弱边框
rgba(46, 117, 254, 0.08)
轻边界、信息分组、非强交互分隔。
不做全局替换

本次只建立智投 Chat 局部 token 和验收口径。

主色服务操作

蓝色只给可推进任务的交互和焦点状态。

辅助色表达语义

成功、警示、危险、信息不能混用。
