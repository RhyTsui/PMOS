# 2026-05-25 日报：登录闭环修复、Chat 体验校准与需求文档留档

## 今日完成

1. 修复登录页持续显示“正在进入”的问题。
   - 发现旧登录 cookie 失效后，`/login` 会被 `proxy` 拦回首页。
   - 首页认证失败后又跳回 `/login`，形成登录页与首页之间的循环。
   - 移除 `/login` 上基于旧 token 的强制跳转。
   - 认证失败时统一清理 cookie 与 localStorage。
   - 外部认证请求增加 8 秒超时，避免登录态校验长时间悬挂。
