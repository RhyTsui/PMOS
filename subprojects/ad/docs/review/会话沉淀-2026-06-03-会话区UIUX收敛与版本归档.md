# 会话沉淀：会话区 UIUX 收敛与版本归档

- 日期：2026-06-03
- 范围：会话区消息渲染收敛、运行态展示、数据结果区、输入推荐按钮、回归测试与版本归档
- 状态：已完成，待推送 GitLab

## 问题背景

本次会话主要处理消息渲染项在主消息区外露、运行态占位重复、数据结果标题冗余、推荐按钮不随结果变化，以及能力缺口与正常结果混排的问题。目标是把已注册的渲染项按主消息、过程依据、输入推荐和附件承接做统一收敛，同时不改变后端路由、工具调用、语义契约和 Trace 上报。

## 已完成事项

- 新增消息展示投影层，统一决定哪些 region 进入主消息区、右侧过程与依据、输入框推荐和隐藏区。
- 重写消息结果渲染，去掉默认“已整理回答 / 以下内容...”壳，`decision-card` 固定展示为“查询结果”。
- 将 `capability_gap`、`workflow-trace`、`evidence-panel`、`source-list`、`asset-reference`、`disclosure-panel`、`form-input`、`feedback-panel` 等按规则分流，避免主消息区外露。
- 新增运行态卡片，发送后即时显示，占位不再出现无意义省略号。
- 收敛数据结果区为图/表切换的统一面板，支持多指标选择和导出。
- 将当前结果动作映射为输入框上方动态推荐按钮，不再固定展示默认推荐。
- 补齐回归测试，覆盖消息投影、能力缺口分流、推荐按钮与数据结果区行为。
