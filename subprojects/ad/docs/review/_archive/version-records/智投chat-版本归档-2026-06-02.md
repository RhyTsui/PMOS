# 智投chat 版本归档 2026-06-02

## 归档范围

本次归档覆盖自动化服务收口、项目绑定与权限过滤、推荐采样旁路修复，以及 8002 服务恢复过程。

## 关键变更

1. 自动化服务补齐后台调度，按 `next_run_at` 自动触发到期任务。
2. 自动化任务、执行记录、附件结果统一透传 `project_binding`，并按项目范围过滤。
3. 会话、搜索、附件、自动化中心等入口按当前项目做动态可见性控制。
4. 推荐服务改为从当前会话反查项目绑定后再采样定时报表任务，避免全量任务旁路。
5. 修正推荐服务递归调用问题，避免模型配置启用后把推荐链路直接打崩。
6. 服务由 production `dist/server.js` 切回 development 启动，恢复 `8002` 正常响应。

## 回归状态

- `http://127.0.0.1:8002/` 返回登录跳转，首页链路正常。
- `/api/xiaoqiao/conversations`、`/api/xiaoqiao/scheduled-tasks`、`/api/xiaoqiao/recommendations` 均已恢复为正常鉴权响应。
- 现存 TypeScript 报错来自仓库内其他既有改动，不属于本次归档范围。
