## 6. 大模型调用点示意图

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户
    participant FE as 会话前端
    participant RQ as RequestUnderstanding
    participant PL as Planner
    participant AR as PlanArbitrator
    participant EX as 执行/工具层
    participant CO as Answer Composer
    participant SA as Safety Gate
    participant DP as Disp / 用户展示

    U->>FE: 输入问题
    FE->>RQ: 结构化理解请求
    RQ->>PL: 规划候选
    PL->>AR: 弱信号候选 + 风险建议
    AR->>EX: 选择执行路径
    EX-->>PL: 工具输入建议
    EX-->>CO: 工具结果 / 公开来源 / 知识片段
    CO->>SA: 证据约束下生成自然语言
    SA-->>DP: 安全与一致性通过后返回
    DP-->>FE: 渲染主消息、过程和可追溯依据
```

## 7. 自动化介绍图（Chat-first 任务中心）

```mermaid
flowchart LR
  U2[用户提出自动化目标] --> PL2a[Understanding + Planner]
  PL2a --> PROP[任务提案卡]
  PROP -->|用户确认| CREATE[TaskCreated]
  PROP -->|继续追问| CLAR[补齐槽位]
  CREATE --> SCH[Task Template/Worker 调度]
  SCH --> RUN[TaskRun 执行]
  RUN --> S_OK[执行成功]
  RUN --> S_FAIL[执行失败]
  S_OK --> MSG1[task_run_completed]
  S_FAIL --> MSG2[task_run_failed + 重试建议]
  MSG1 --> HIGHLIGHT[左侧列表高亮未读]
  MSG2 --> HIGHLIGHT
  HIGHLIGHT --> READ[用户打开会话查看结果]
  READ --> FEEDBACK[下一步动作/参数修正]
  FEEDBACK --> U2
```

## 使用说明（高清导出）

- 建议在支持 Mermaid 的渲染器中，分别以独立页面导出 PNG/SVG 后再拼装。
- 如需统一风格输出，可先设置统一背景、字体和线宽，再用 300~600 dpi 导出，作为“image2 高清版”存档。
- 当前图示已与 `ENTERPRISE_AI_CHAT_OS_SPEC.md`、`ai-chat-implementation-guardrails.md`、`ui-guardrail.md` 对齐。
