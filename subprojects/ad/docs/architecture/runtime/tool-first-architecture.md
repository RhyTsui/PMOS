# Tool-First Architecture

> Parent: `docs/architecture/ENTERPRISE_AI_CHAT_OS_SPEC.md`

## 定义

Tool-first 是执行原则：事实查询、指标计算、业务状态、真实动作、文件解析、任务状态和报表生成优先由工具或 MCP 完成；LLM 负责语言组织、解释、追问与草稿。

## 适用场景

- 必须工具：真实数据、账户/资产状态、业务动作、权限相关、高风险决策、报表产物。
- 可模型直答：无事实依赖的概念解释、写作草稿、开放式建议。
- 需要追问：缺少工具必填参数、权限主体、时间范围、对象范围。

## 降级

工具不可达时可解释不可达原因、提出下一步或请求用户补充，但不得伪造工具结果。
