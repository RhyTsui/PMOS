# Chat Answer Views

Status: P0.6/P0.7 architecture refresh.

Answer views describe the shape of the response the user expects.

## View Types

- summary
- table
- trend
- comparison
- diagnosis
- explanation
- operation_status

## Display Rule

Main message should show the result, analysis conclusion, or required user action. Process detail, logs, raw steps, and artifacts should be projected to the side panel or runtime disclosure surface.
