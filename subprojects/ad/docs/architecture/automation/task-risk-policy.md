# Task Risk Policy

## 风险分级

| 等级 | 说明 | 自动化策略 | 示例 |
|---|---|---|---|
| L0 | 公开/低风险摘要 | 可直接创建 | 帮助文档查询 |
| L1 | 读取普通业务数据 | 创建时确认范围 | GI 日报（公开资讯） |
| L2 | 读取敏感明细 | 必须权限校验 | 指标监控（含业务数据） |
| L3 | 生成文件/报告 | 必须说明数据范围 | 拼表、聚合表 |
| L4 | 触发业务工作流 | 必须二次确认 | 发起联调流程 |
| L5 | 修改投放/预算/配置 | 禁止自动执行 | 修改广告预算 |

## 确认机制

### L0/L1 — 自动通过
- 创建任务时直接生成 task_proposal，用户确认后创建。
- 无需额外确认步骤。

### L2 — 权限校验
- 创建任务时检查用户权限。
- 无权限时返回权限不足提示。

### L3 — 数据范围说明
- task_proposal 卡片中必须说明数据范围。
- 用户确认后才创建。

### L4 — 二次确认
- task_proposal 卡片标注"高风险操作"。
- 用户必须点击"确认执行"按钮。
- 确认后生成 task_created。

### L5 — 禁止自动执行
- 只生成建议或等待人工确认。
- 文案："该任务涉及高风险操作，我可以定期检查并给出建议，但真正修改预算、计划或配置前必须由你确认。"
- 不允许自动执行，只能通过 task_needs_action 等待人工。

## 模板默认风险等级

| 模板 | 默认风险 | 说明 |
|---|---|---|
| scheduled_join_table | L3 | 生成文件 |
| scheduled_aggregate_table | L3 | 生成文件 |
| gi_keyword_daily_digest | L1/L2 | 取决于数据敏感度 |
| scheduled_metric_monitor | L2/L3 | 取决于监控范围 |

## 实现约束

1. 风险等级由 template registry 定义，不允许用户降级。
2. 运行时校验风险等级，L4/L5 必须经过确认流程。
3. 前端不展示风险等级数值，只展示用户可读文案。
