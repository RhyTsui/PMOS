# 小乔智投待补知识清单

> 用途：持续记录需要后续集中补入知识库、受控术语、运行时策略或测试样本的内容。本文不直接定义产品功能，也不替代 PRD / 系统设计 / 工程清单。

## 1. 维护规则

- 每发现一个知识缺口，先记录到本文，不阻断当前设计和工程推进。
- 每条缺口必须标明放置位置：通用知识库、受控术语索引、问数策略 alias、MCP 返回样本、测试集、后台配置说明。
- 不把实时项目数据、用户权限、报表结果、包状态、联调状态写入知识库。
- 会改变执行行为的内容优先进入运行时策略或配置，不直接写成知识库自由文本。
- 后续集中处理时，按 P0 / P1 / P2 批量补齐，并回归问数测试集和真实链路。

## 5. 当前处理原则

- 受控术语用于“理解用户说的是什么”，不直接生成执行事实。
- Alias 用于“是否需要调用某个字典 tool”，不直接替代 MCP 返回值。
- MCP 返回样本用于“校验字段映射”，不是用户可见知识。
- 指标口径解释必须内部口径库优先，外部联网只能补充行业背景和公开方法论。
- 任何涉及项目数据、资产、会话、自动化任务、包状态的内容，都必须走权限和 MCP / Workflow 实时查询，不进入知识库。
