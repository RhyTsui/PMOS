# 小乔智投设计阶段缺口清单

## 1. 使用规则

本文只记录设计缺口，不拆工程任务，不指定具体代码文件。缺口关闭后，才能进入对应模块的稳定实施拆解。

缺口分类：

- `契约缺口`：缺服务字段、返回样本、错误枚举或 SDK 映射。
- `交互缺口`：缺用户流程、确认点、展示规则。
- `策略缺口`：缺优先级、边界、降级规则。
- `验收缺口`：缺可验证样本、断言或测试口径。

## 5. 当前不能用工程实现替代的设计问题

- 不能用写死项目名解决项目解析问题。
- 不能用 Prompt 自由生成包状态、数据结果、联调结论。
- 不能用知识库自由文本替代 MCP 返回样本。
- 不能把 Trace 当成资产或证据。
- 不能把测试集通过理解为用户闭环完成。
- 不能把“已整理需求”当成“已创建 Case”。
