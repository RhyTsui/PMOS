# v0.6 看数据服务测试用例

版本目标：让看数据服务稳定调用报表 MCP，默认补数据异常检查，并在指标未覆盖时进入需求确认。

## 查数主链

| 编号 | 提问 | 期望路径 | 验收点 |
| --- | --- | --- | --- |
| RQ-001 | 指间山海今天消耗多少 | 自然语言查数 -> 报表 MCP -> 数据异常检查 | 思维链展示报表工具请求和返回；正文数值必须来自工具返回 |
| RQ-002 | 查看当前项目近7天投放效果 | 投放效果分析 -> 近7天大盘 -> 前7天基准 | 不追问媒体和指标，默认展示项目大盘 |
| RQ-003 | 查看当前项目昨天激活、注册和付费 | 自然语言查数 -> 报表 MCP -> 数据异常检查 | 指标数组包含 activation、register、payment |
| RQ-004 | 查看当前项目近30天 ROI 趋势 | 自然语言查数 -> 报表 MCP -> 数据异常检查 | 时间范围为近30天，返回前不生成示例数据 |
| RQ-005 | 查看当前项目留存和 ARPPU | 自然语言查数 -> 报表 MCP -> 数据异常检查 | 支持 retention_d1、arppu 指标映射 |

## 异常与边界

| 编号 | 提问 | 期望路径 | 验收点 |
| --- | --- | --- | --- |
| RQ-101 | 查看当前项目 LTV | 指标需求确认 | 告知当前报表工具不支持，记录指标需求，不调用相近指标冒充 |
| RQ-102 | 查看当前项目素材疲劳度 | 指标需求确认 | 追问指标口径、数据源、维度和展示方式 |
| RQ-103 | 查看当前项目近7天投放效果和操作记录 | 投放效果分析 -> 报表 MCP -> 巨量操作记录 | 只有用户明确要求时才查询操作记录 |
| RQ-104 | 报表 MCP 返回空表 | 数据异常检查 | 正文优先提示空返回，不输出确定性业务结论 |
| RQ-105 | 报表 MCP 返回字段缺失 | 数据异常检查 | 提示缺少字段映射或指标口径 |
| RQ-106 | 上周腾讯广告媒体的安卓总消耗是多少，且媒体字典能力未配置 | 能力预检 -> 知识库兜底说明 -> 阻断报表查询 | 明确提示缺少媒体平台匹配或终端匹配能力，不调用报表主工具 |
| RQ-107 | 上周腾讯广告媒体的安卓总消耗是多少，且没有当前项目或 appId | 条件预检 -> 追问查询范围 | 明确提示需要先确认当前项目或 appId，不调用媒体/终端字典和报表主工具 |
| RQ-108 | 报表工具返回空表，但媒体编号、终端范围、项目和时间均已补齐 | 数据异常检查 | 提示没有查到符合条件的数据，并展示本次使用的查询条件 |

## 自动化日报

| 编号 | 提问 | 期望路径 | 验收点 |
| --- | --- | --- | --- |
| AR-001 | 创建游戏项目投放日报 | 自动报表 -> 游戏项目日报模板 | 模板包含项目总数据、广告量、媒体、应用类型、团队和 iOS 自然量扣除口径 |
| AR-002 | 每天9点生成当前项目日报 | 自动报表 -> 确认维度指标 -> 创建任务 | 创建前需要确认维度、指标、时间和频率 |
| AR-003 | 修改已配置日报任务 | 自动报表任务管理 | 支持暂停、开启和修改，并保留操作记录 |

## 对接需求

| 编号 | 提问 | 期望路径 | 验收点 |
| --- | --- | --- | --- |
| DM-001 | 我有一个监测回传对接文档 | 对接需求确认 -> 文档解析 -> 配置方式确认 | 文档无特殊操作且参数齐全时进入配置能力 |
| DM-002 | 做一个行业数据采集对接 | 对接需求确认 -> 文档解析 | 要求样例数据、字段口径、更新频率和验收方式 |
| DM-003 | 创建监测链接 | 监测链接交付 | 先查权限和已有链接，再创建或返回阻塞项 |
