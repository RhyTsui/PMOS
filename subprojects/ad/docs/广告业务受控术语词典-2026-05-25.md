# 广告业务受控术语词典

- 版本：v0.1 草稿
- 日期：2026-05-25
- 用途：用于用户输入后的前置术语归一化。系统只根据本文档中的受控词、别名和规则完成词义收敛，不在该阶段进行大范围知识检索。
- 适用范围：广告投放、归因、回传、数据报表、效果分析、问题排查、联调准备。

---

## 1. 使用原则

### 1.1 归一化目标

用户输入中出现广告业务词、口语简称、媒体侧名词、指标别名时，优先映射为本文档定义的“标准词”。

归一化结果建议包含：

```json
{
  "raw_text": "用户原始输入",
  "normalized_terms": [
    {
      "raw": "用户原词",
      "standard": "标准词",
      "category": "词类",
      "confidence": "high|medium|low",
      "need_clarification": false
    }
  ],
  "clarification_questions": []
}
```

### 1.2 匹配优先级

1. 精确命中标准词。
2. 精确命中别名、简称、英文缩写。
3. 命中“常见说法”，且上下文能确认业务含义。
4. 同一个词可能指向多个标准词时，不强行归一，先追问。

### 1.3 不做的事

1. 不根据上下文自行创造新术语。
2. 不把未收录的媒体规则、平台口径、历史经验扩展为标准答案。
3. 不在归一化阶段解释复杂业务原因。
4. 不把“疑似问题”直接归因为具体原因，只归一到问题类型或待确认字段。

### 1.4 低置信度追问规则

出现以下情况时，归一化结果应标记 `need_clarification=true`：

1. “转化”未说明是激活、注册、付费、留存或自定义事件。
2. “成本”未说明是媒体消耗、内部成本、现金成本或补贴后成本。
3. “收入”未说明是首日收入、累计收入、归因收入、订单收入或媒体侧收入。
4. “ROI”未说明时间窗口，如首日、7日、30日或累计。
5. “回传失败”未说明媒体、应用、事件、时间范围。
6. “数据不对”未说明对比对象，如媒体后台、内部报表、订单系统、日志。

## 2. 词类

| 词类 | 说明 | 示例 |
| --- | --- | --- |
| 业务对象 | 投放和数据分析中的核心对象 | 应用、媒体、账号、计划、单元、创意 |
| 媒体与渠道 | 广告流量来源与合作平台 | 巨量引擎、腾讯广告、快手磁力引擎 |
| 事件 | 用户行为或广告链路事件 | 激活、注册、付费、次留 |
| 指标 | 可计算、可对比的业务度量 | 消耗、展示、点击、转化率、ROI |
| 归因与回传 | 用户归属、事件上报、媒体反馈链路 | 归因、回传、归因窗口、深度回传 |
| 维度 | 报表聚合或筛选口径 | 日期、应用、媒体、账号、计划、素材 |
| 问题类型 | 排查时的标准问题归类 | 数据差异、回传失败、转化偏低 |
| 动作 | 用户希望系统执行的业务动作 | 查询、对比、解释、排查、生成报告 |

## 3. 业务对象

### 3.1 应用

- 标准词：应用
- 词类：业务对象
- 别名：App、产品、游戏、项目、投放产品
- 定义：广告投放对应的具体产品实体，通常用于区分数据归属和投放目标。
- 归一化规则：用户说“这个游戏”“这个产品”“App”时，如上下文已有唯一对象，归一为“应用”；否则要求补充应用名称。
- 不应混淆：包体、渠道包、媒体账号。

### 3.2 包体

- 标准词：包体
- 词类：业务对象
- 别名：安装包、包、APK、IPA、渠道包、包名
- 定义：用户下载安装的应用构建产物，常用于联调、白名单、归因验证和版本排查。
- 归一化规则：“包名”如果指 Android package name，可归一为“包体标识”；如果指安装文件，归一为“包体”。
- 不应混淆：应用、版本、下载链接。

### 3.3 媒体

- 标准词：媒体
- 词类：业务对象
- 别名：广告平台、渠道、流量平台、买量平台、媒体侧
- 定义：广告投放平台或流量来源。
- 归一化规则：用户说“平台数据”“渠道数据”时，如上下文是广告流量来源，归一为“媒体”。
- 不应混淆：自然渠道、应用商店渠道、内部系统。

### 3.4 广告账号

- 标准词：广告账号
- 词类：业务对象
- 别名：投放账号、媒体账号、账户、广告账户、account
- 定义：媒体侧承载投放配置、消耗、计划和权限的账号。
- 归一化规则：“账号”在广告投放上下文中默认归一为“广告账号”；涉及登录或用户权限时不归一。
- 不应混淆：系统登录账号、游戏账号、用户 ID。

### 3.5 广告计划

- 标准词：广告计划
- 词类：业务对象
- 别名：计划、campaign、Campaign、投放计划
- 定义：媒体侧投放管理层级，通常承载目标、预算、投放周期等配置。
- 归一化规则：用户说“计划掉量”“计划不起量”“campaign 表现”时归一为“广告计划”。
- 不应混淆：广告组、广告单元、创意。

### 3.6 广告单元

- 标准词：广告单元
- 词类：业务对象
- 别名：单元、ad group、adgroup、广告组、推广单元
- 定义：广告计划下的投放配置层级，常承载定向、出价、素材组合等信息。
- 归一化规则：不同媒体命名不一致时，优先归一为“广告单元”，保留原媒体层级名作为别名。
- 不应混淆：广告计划、创意。

### 3.7 创意

- 标准词：创意
- 词类：业务对象
- 别名：素材、广告素材、creative、视频、图片、文案、落地页创意
- 定义：面向用户展示的广告内容及其组合。
- 归一化规则：当用户讨论点击率、转化率、审核、衰退、跑量时，“素材”归一为“创意”。
- 不应混淆：素材文件、素材包、落地页。

### 3.8 落地页

- 标准词：落地页
- 词类：业务对象
- 别名：LP、landing page、广告落地页、下载页、承接页
- 定义：用户点击广告后进入的页面，用于承接下载、预约、注册或其他转化动作。
- 归一化规则：“下载页”“承接页”在广告点击后路径中归一为“落地页”。
- 不应混淆：应用首页、官网、活动页。

### 3.9 用户标识

- 标准词：用户标识
- 词类：业务对象
- 别名：用户 ID、设备 ID、openid、oaid、idfa、imei、android id
- 定义：用于识别用户、设备或媒体归因链路的标识。
- 归一化规则：具体标识应保留原词，如 OAID、IDFA；泛称“用户 ID”归一为“用户标识”。
- 不应混淆：广告账号、媒体账号。

## 4. 媒体与渠道

### 4.1 巨量引擎

- 标准词：巨量引擎
- 词类：媒体与渠道
- 别名：巨量、头条、抖音广告、穿山甲、OceanEngine、字节广告
- 定义：字节系广告投放平台。
- 归一化规则：用户说“巨量”“抖音数据”“头条消耗”时，如语境是广告投放，归一为“巨量引擎”。
- 不应混淆：抖音自然流量、抖音小店。

### 4.2 腾讯广告

- 标准词：腾讯广告
- 词类：媒体与渠道
- 别名：广点通、GDT、腾讯系、腾讯流量
- 定义：腾讯系广告投放平台。
- 归一化规则：“广点通”归一为“腾讯广告”。
- 不应混淆：微信开放平台、应用宝自然量。

### 4.3 快手磁力引擎

- 标准词：快手磁力引擎
- 词类：媒体与渠道
- 别名：快手、磁力、快手广告
- 定义：快手系广告投放平台。
- 归一化规则：“快手投放”“磁力数据”归一为“快手磁力引擎”。
- 不应混淆：快手自然内容流量。

### 4.4 自然量

- 标准词：自然量
- 词类：媒体与渠道
- 别名：自然流量、自然用户、非买量、organic
- 定义：未被广告投放归因的用户来源。
- 归一化规则：“不是广告来的用户”可归一为“自然量”。
- 不应混淆：未归因用户、归因失败用户。

### 4.5 未归因流量

- 标准词：未归因流量
- 词类：媒体与渠道
- 别名：未归因、无归因、归不到渠道、unknown
- 定义：广告链路中没有匹配到明确媒体或广告对象的流量。
- 归一化规则：当用户强调“本应归因但没有归上”时，归一为“未归因流量”，不要归为“自然量”。
- 不应混淆：自然量。

## 5. 广告事件

### 5.1 展示

- 标准词：展示
- 词类：事件
- 别名：曝光、展现、impression、show
- 定义：广告被展示给用户的事件。
- 归一化规则：“曝光”和“展现”统一归一为“展示”。
- 不应混淆：点击、播放。

### 5.2 点击

- 标准词：点击
- 词类：事件
- 别名：click、广告点击、点击广告
- 定义：用户点击广告的事件。
- 归一化规则：“点广告”“广告被点”归一为“点击”。
- 不应混淆：落地页访问、下载。

### 5.3 激活

- 标准词：激活
- 词类：事件
- 别名：新增、安装激活、首次启动、activate、activation
- 定义：用户安装应用后首次打开并被记录为有效新增的事件。
- 归一化规则：“新增”在买量上下文中通常归一为“激活”；如涉及注册用户数，需追问。
- 不应混淆：安装、注册、新增账号。

### 5.4 注册

- 标准词：注册
- 词类：事件
- 别名：创角、建号、创建角色、sign up、register
- 定义：用户完成账号注册或创建角色的事件。
- 归一化规则：游戏业务中“创角”归一为“注册”，同时保留原词“创角”作为业务别名。
- 不应混淆：激活、登录。

### 5.5 付费

- 标准词：付费
- 词类：事件
- 别名：支付、充值、下单、购买、pay、purchase
- 定义：用户完成支付并产生有效收入的事件。
- 归一化规则：“充值”和“支付”在游戏广告场景归一为“付费”。
- 不应混淆：订单创建、支付成功、退款后净收入。

### 5.6 首日付费

- 标准词：首日付费
- 词类：事件
- 别名：D1 付费、激活当日付费、当日付费
- 定义：用户激活当天发生的付费事件或付费金额，具体应结合指标口径判断。
- 归一化规则：如用户问“首日付费人数”，归一到“首日付费人数”；如问“首日付费”，需结合上下文判断是事件还是指标。
- 不应混淆：首日收入、首日 ROI。

### 5.7 次日留存

- 标准词：次日留存
- 词类：事件
- 别名：次留、D1 留存、第二天留存
- 定义：用户激活后的次日仍有有效活跃行为。
- 归一化规则：“次留”统一归一为“次日留存”。
- 不应混淆：首日留存、7 日留存。

### 5.8 自定义事件

- 标准词：自定义事件
- 词类：事件
- 别名：自定义转化、深度事件、关键行为、目标事件
- 定义：根据业务需要定义并上报的非通用事件。
- 归一化规则：当用户只说“转化事件”但未说明具体类型时，先归一为“转化事件”，并追问事件名称。
- 不应混淆：标准事件、媒体转化目标。

## 6. 指标

### 6.1 广告消耗

- 标准词：广告消耗
- 词类：指标
- 别名：消耗、花费、成本、cost、spend、广告花费
- 定义：广告投放在媒体侧产生的花费金额。
- 归一化规则：投放语境中的“成本”默认归一为“广告消耗”；如涉及获客成本，应归一为 CPA、CPI 或对应成本指标。
- 不应混淆：现金成本、内部成本、综合成本。

### 6.2 展示量

- 标准词：展示量
- 词类：指标
- 别名：曝光量、展现量、impressions、PV
- 定义：广告展示事件的次数。
- 归一化规则：“曝光数”“展现数”归一为“展示量”。
- 不应混淆：覆盖人数、播放量。

### 6.3 点击量

- 标准词：点击量
- 词类：指标
- 别名：点击数、clicks
- 定义：广告点击事件的次数。
- 归一化规则：“点了多少次”归一为“点击量”。
- 不应混淆：点击人数、访问量。

### 6.4 点击率

- 标准词：点击率
- 词类：指标
- 别名：CTR、click-through rate
- 定义：点击量 / 展示量。
- 公式：点击率 = 点击量 / 展示量
- 归一化规则：“CTR”归一为“点击率”。
- 不应混淆：转化率、到达率。

### 6.5 激活量

- 标准词：激活量
- 词类：指标
- 别名：新增量、激活数、新增用户数、activations
- 定义：被记录为有效激活的用户数量。
- 归一化规则：“新增”在买量效果语境中优先归一为“激活量”；如果用户讨论注册账号，需追问。
- 不应混淆：安装量、注册量。

### 6.6 激活成本

- 标准词：激活成本
- 词类：指标
- 别名：CPA、CPI、获客成本、单激活成本、激活单价
- 定义：平均获得一个有效激活所消耗的广告费用。
- 公式：激活成本 = 广告消耗 / 激活量
- 归一化规则：游戏买量中“CPA”经常指激活成本；若媒体目标是注册、付费等其他事件，需要按具体转化目标追问。
- 不应混淆：注册成本、付费成本。

### 6.7 转化量

- 标准词：转化量
- 词类：指标
- 别名：转化数、conversions、目标完成数
- 定义：达到指定转化事件的次数或人数。
- 归一化规则：必须绑定转化事件。用户只说“转化量”时，应追问转化事件。
- 不应混淆：激活量、注册量、付费人数。

### 6.8 转化率

- 标准词：转化率
- 词类：指标
- 别名：CVR、conversion rate
- 定义：转化量 / 上游基数。上游基数可能是点击量、展示量、激活量或注册量。
- 归一化规则：用户只说“转化率”时，必须确认分子和分母。
- 不应混淆：点击率、付费率、留存率。

### 6.9 付费人数

- 标准词：付费人数
- 词类：指标
- 别名：付费用户数、充值人数、PU、pay users
- 定义：完成有效付费的去重用户数。
- 归一化规则：“付费用户”作为指标时归一为“付费人数”。
- 不应混淆：付费次数、订单数。

### 6.10 付费率

- 标准词：付费率
- 词类：指标
- 别名：PUR、pay rate、支付率
- 定义：付费人数 / 指定用户基数。
- 归一化规则：用户只说“付费率”时，需确认基数是激活用户、注册用户、活跃用户还是归因用户。
- 不应混淆：转化率、首日付费率。

### 6.11 收入

- 标准词：收入
- 词类：指标
- 别名：流水、营收、充值金额、GMV、revenue、付费金额
- 定义：用户付费带来的金额。具体口径需确认是否含退款、税费、渠道分成和时间窗口。
- 归一化规则：“流水”“充值金额”归一为“收入”，并保留收入口径待确认。
- 不应混淆：利润、回收、ROI。

### 6.12 首日收入

- 标准词：首日收入
- 词类：指标
- 别名：D1 收入、首日回收、激活当日收入、D0 收入
- 定义：用户激活当天产生的收入。
- 归一化规则：“首日回收”如指金额，归一为“首日收入”；如指比率，归一为“首日 ROI”。
- 不应混淆：首日 ROI、累计收入。

### 6.13 累计收入

- 标准词：累计收入
- 词类：指标
- 别名：总收入、累计回收、LTV 收入、N日收入
- 定义：指定时间窗口内归因用户产生的累计收入。
- 归一化规则：“7日收入”“30日收入”归一为“累计收入”，并记录时间窗口。
- 不应混淆：首日收入、媒体侧收入。

### 6.14 ROI

- 标准词：ROI
- 词类：指标
- 别名：投资回报率、回收率、回本率、return on investment
- 定义：收入 / 广告消耗，用于衡量广告投入回收效果。
- 公式：ROI = 收入 / 广告消耗
- 归一化规则：用户只说“ROI”时，应追问时间窗口和收入口径。
- 不应混淆：利润率、ROAS。若团队内部把 ROAS 与 ROI 等同使用，需在后续版本明确。

### 6.15 首日 ROI

- 标准词：首日 ROI
- 词类：指标
- 别名：D1 ROI、D0 ROI、首日回收率、首日回本率
- 定义：首日收入 / 广告消耗。
- 公式：首日 ROI = 首日收入 / 广告消耗
- 归一化规则：“首日回收”如果上下文是百分比或比率，归一为“首日 ROI”。
- 不应混淆：首日收入、累计 ROI。

### 6.16 7日 ROI

- 标准词：7日 ROI
- 词类：指标
- 别名：D7 ROI、七日 ROI、7日回收率
- 定义：激活后 7 日内累计收入 / 广告消耗。
- 归一化规则：“七日回本”“D7 回收”归一为“7日 ROI”。
- 不应混淆：首日 ROI、30日 ROI。

### 6.17 留存率

- 标准词：留存率
- 词类：指标
- 别名：retention、留存、次留率、7留、30留
- 定义：指定日期仍然活跃的用户数 / 基准用户数。
- 归一化规则：“次留率”归一为“次日留存率”；“7留”归一为“7日留存率”。
- 不应混淆：活跃率、回流率。

### 6.18 ARPU

- 标准词：ARPU
- 词类：指标
- 别名：人均收入、平均每用户收入
- 定义：收入 / 用户数。
- 归一化规则：“人均收入”归一为“ARPU”，但需确认用户基数和时间窗口。
- 不应混淆：ARPPU。

### 6.19 ARPPU

- 标准词：ARPPU
- 词类：指标
- 别名：付费用户人均收入、付费人均
- 定义：收入 / 付费人数。
- 归一化规则：“付费人均”归一为“ARPPU”。
- 不应混淆：ARPU。

### 6.20 LTV

- 标准词：LTV
- 词类：指标
- 别名：生命周期价值、用户生命周期价值、长期价值
- 定义：用户在指定生命周期窗口内贡献的累计价值。
- 归一化规则：“长期回收”“生命周期收入”可归一为“LTV”，但必须确认窗口和收入口径。
- 不应混淆：累计收入、ROI。

## 7. 归因与回传

### 7.1 归因

- 标准词：归因
- 词类：归因与回传
- 别名：用户归属、渠道归属、 attribution、归到媒体
- 定义：把用户或事件归属到某个广告来源的过程。
- 归一化规则：“这个用户算谁的”“归到哪个渠道”归一为“归因”。
- 不应混淆：回传、上报。

### 7.2 归因窗口

- 标准词：归因窗口
- 词类：归因与回传
- 别名：归因周期、点击窗口、展示窗口、lookback window
- 定义：媒体触点与转化事件之间可被认定为有效归因的时间范围。
- 归一化规则：“几天内算转化”“窗口期”归一为“归因窗口”。
- 不应混淆：统计周期、报表日期。

### 7.3 归因口径

- 标准词：归因口径
- 词类：归因与回传
- 别名：归因规则、归因逻辑、归因方式、计算口径
- 定义：判断事件是否归属到广告来源的一组规则。
- 归一化规则：“为什么媒体和内部归因不一样”中归一出“归因口径”。
- 不应混淆：指标口径、收入口径。

### 7.4 回传

- 标准词：回传
- 词类：归因与回传
- 别名：事件回传、转化回传、postback、callback、上报给媒体
- 定义：把应用内转化事件或归因结果发送给媒体侧的过程。
- 归一化规则：“传给媒体”“回给巨量”“postback”归一为“回传”。
- 不应混淆：客户端上报、服务端上报、归因。

### 7.5 深度回传

- 标准词：深度回传
- 词类：归因与回传
- 别名：深度事件回传、付费回传、关键行为回传
- 定义：激活以外的注册、付费、留存、自定义事件等深层行为回传给媒体。
- 归一化规则：“付费传媒体”“注册回传”归一为“深度回传”，并记录具体事件。
- 不应混淆：激活回传。

### 7.6 激活回传

- 标准词：激活回传
- 词类：归因与回传
- 别名：新增回传、安装回传、激活 postback
- 定义：把激活事件回传给媒体。
- 归一化规则：“新增没传过去”“激活没回媒体”归一为“激活回传”。
- 不应混淆：深度回传。

### 7.7 客户端上报

- 标准词：客户端上报
- 词类：归因与回传
- 别名：SDK 上报、端上上报、埋点上报
- 定义：应用客户端通过 SDK 或埋点发送事件数据。
- 归一化规则：“SDK 没报”“端上没打点”归一为“客户端上报”。
- 不应混淆：服务端上报、媒体回传。

### 7.8 服务端上报

- 标准词：服务端上报
- 词类：归因与回传
- 别名：S2S、server-to-server、后端上报、服务端打点
- 定义：业务服务端向数据系统或媒体发送事件数据。
- 归一化规则：“后端传事件”“S2S 回传”根据方向归一为“服务端上报”或“回传”。
- 不应混淆：客户端上报。

### 7.9 媒体回执

- 标准词：媒体回执
- 词类：归因与回传
- 别名：回执、响应、返回码、response、媒体响应
- 定义：媒体接收回传请求后的返回结果。
- 归一化规则：“媒体返回失败”“返回码不对”归一为“媒体回执”。
- 不应混淆：回传日志、业务处理结果。

## 8. 维度

### 8.1 日期

- 标准词：日期
- 词类：维度
- 别名：天、日、day、date、统计日期
- 定义：按天聚合或筛选数据的时间维度。
- 归一化规则：“昨天”“上周”“近 7 天”不归一为日期值，应另行解析为时间范围。
- 不应混淆：事件时间、回传时间、入库时间。

### 8.2 小时

- 标准词：小时
- 词类：维度
- 别名：分时、小时粒度、hour
- 定义：按小时聚合或筛选数据的时间维度。
- 归一化规则：“看今天分时”归一出维度“小时”。
- 不应混淆：实时数据。

### 8.3 应用维度

- 标准词：应用维度
- 词类：维度
- 别名：按应用、按产品、按游戏、app 维度
- 定义：按应用聚合或筛选数据。
- 归一化规则：“分产品看”归一为“应用维度”。
- 不应混淆：包体维度。

### 8.4 媒体维度

- 标准词：媒体维度
- 词类：维度
- 别名：按媒体、按渠道、平台维度
- 定义：按媒体聚合或筛选数据。
- 归一化规则：“分渠道看消耗”在广告语境归一为“媒体维度”。
- 不应混淆：自然渠道、下载渠道。

### 8.5 广告账号维度

- 标准词：广告账号维度
- 词类：维度
- 别名：按账号、账户维度、account 维度
- 定义：按广告账号聚合或筛选数据。
- 归一化规则：“这个账号 ROI”归一出“广告账号维度”。
- 不应混淆：用户账号维度。

### 8.6 广告计划维度

- 标准词：广告计划维度
- 词类：维度
- 别名：计划维度、campaign 维度
- 定义：按广告计划聚合或筛选数据。
- 归一化规则：“看计划表现”归一出“广告计划维度”。
- 不应混淆：广告单元维度。

### 8.7 创意维度

- 标准词：创意维度
- 词类：维度
- 别名：素材维度、creative 维度、视频维度
- 定义：按创意或素材聚合、筛选或对比数据。
- 归一化规则：“哪个素材转化好”归一出“创意维度”。
- 不应混淆：素材文件维度。

### 8.8 事件时间

- 标准词：事件时间
- 词类：维度
- 别名：发生时间、用户行为时间、event time
- 定义：用户行为实际发生的时间。
- 归一化规则：排查数据延迟或口径差异时，需区分事件时间、回传时间、入库时间。
- 不应混淆：回传时间、入库时间、报表统计日期。

### 8.9 回传时间

- 标准词：回传时间
- 词类：维度
- 别名：发送时间、postback time、传给媒体的时间
- 定义：事件被发送给媒体的时间。
- 归一化规则：“什么时候传过去的”归一为“回传时间”。
- 不应混淆：事件时间、入库时间。

### 8.10 入库时间

- 标准词：入库时间
- 词类：维度
- 别名：写入时间、落库时间、处理时间
- 定义：数据写入内部数据存储或报表系统的时间。
- 归一化规则：“报表什么时候有数据”常需要归一出“入库时间”。
- 不应混淆：事件时间、回传时间。

## 9. 问题类型

### 9.1 数据差异

- 标准词：数据差异
- 词类：问题类型
- 别名：数据不一致、对不上、差数、数不平、报表不一致
- 定义：两个或多个数据来源在同一口径下结果不一致，或用户认为不一致。
- 归一化规则：“数据不对”“和媒体对不上”归一为“数据差异”，并提取对比对象。
- 必要字段：应用、媒体、指标、时间范围、对比对象。
- 不应混淆：数据延迟、无数据。

### 9.2 数据延迟

- 标准词：数据延迟
- 词类：问题类型
- 别名：延迟、没刷新、还没出来、更新慢
- 定义：数据已经产生但尚未在目标报表或目标系统中可见。
- 归一化规则：“今天数据还没出”归一为“数据延迟”。
- 必要字段：指标、时间范围、目标系统、期望刷新时间。
- 不应混淆：数据缺失、回传失败。

### 9.3 数据缺失

- 标准词：数据缺失
- 词类：问题类型
- 别名：没数据、空了、查不到、数据断了
- 定义：预期应存在的数据没有出现。
- 归一化规则：“某计划没数据”归一为“数据缺失”。
- 必要字段：对象、指标、时间范围、是否新建对象。
- 不应混淆：数据延迟、权限不可见。

### 9.4 回传失败

- 标准词：回传失败
- 词类：问题类型
- 别名：传不过去、媒体没收到、postback 失败、回调失败
- 定义：事件未成功发送给媒体或媒体未成功接收。
- 归一化规则：“巨量没收到付费”归一为“回传失败”，并提取媒体和事件。
- 必要字段：媒体、应用、事件、时间范围、样例用户标识。
- 不应混淆：归因失败、媒体报表延迟。

### 9.5 归因失败

- 标准词：归因失败
- 词类：问题类型
- 别名：归不上、渠道丢了、归因不到、没有归因
- 定义：用户或事件没有被正确归属到广告来源。
- 归一化规则：“用户没归到巨量”归一为“归因失败”。
- 必要字段：媒体、应用、用户标识、事件、触点时间、事件时间。
- 不应混淆：回传失败。

### 9.6 转化偏低

- 标准词：转化偏低
- 词类：问题类型
- 别名：转化差、转化下降、转化掉了、CVR 低
- 定义：指定转化指标低于预期、历史水平或对照对象。
- 归一化规则：“转化不好”归一为“转化偏低”，并追问转化事件。
- 必要字段：转化事件、对比基准、时间范围、对象维度。
- 不应混淆：点击率偏低、成本升高。

### 9.7 成本升高

- 标准词：成本升高
- 词类：问题类型
- 别名：成本变贵、单价升高、CPA 高、CPI 高
- 定义：单位目标事件的广告成本升高。
- 归一化规则：“成本高了”归一为“成本升高”，同时确认成本指标。
- 必要字段：成本指标、时间范围、对象维度、对比基准。
- 不应混淆：消耗升高。

### 9.8 消耗异常

- 标准词：消耗异常
- 词类：问题类型
- 别名：花费异常、消耗突增、消耗突降、跑飞、不花钱
- 定义：广告消耗与预期、预算、历史趋势或计划状态明显不一致。
- 归一化规则：“突然不花钱”“消耗跑飞”归一为“消耗异常”。
- 必要字段：媒体、账号、计划、时间范围、预算或预期。
- 不应混淆：成本升高。

### 9.9 起量困难

- 标准词：起量困难
- 词类：问题类型
- 别名：不起量、跑不出去、没量、冷启动困难
- 定义：广告计划或创意无法获得足够展示、点击或消耗。
- 归一化规则：“计划跑不动”归一为“起量困难”。
- 必要字段：媒体、账号、计划、创意、出价、预算、审核状态。
- 不应混淆：转化偏低。

### 9.10 ROI 偏低

- 标准词：ROI 偏低
- 词类：问题类型
- 别名：回收差、回本差、ROI 掉了、不赚钱
- 定义：ROI 低于目标、历史或同类对象。
- 归一化规则：“回收差”如上下文是比率，归一为“ROI 偏低”。
- 必要字段：ROI 类型、时间窗口、收入口径、对象维度、对比基准。
- 不应混淆：收入下降、成本升高。

## 10. 动作

### 10.1 查询

- 标准词：查询
- 词类：动作
- 别名：看一下、查一下、拉一下、给我数据、取数
- 定义：获取某个对象、指标、时间范围下的数据。
- 归一化规则：“帮我看昨天巨量消耗”归一出动作“查询”。

### 10.2 对比

- 标准词：对比
- 词类：动作
- 别名：比较、环比、同比、和某某比、对照
- 定义：在两个或多个对象、时间段或数据来源之间比较指标差异。
- 归一化规则：“和媒体后台对一下”归一出动作“对比”。

### 10.3 解释

- 标准词：解释
- 词类：动作
- 别名：说明、讲一下、什么意思、怎么算
- 定义：说明指标、规则、结果或差异的业务含义。
- 归一化规则：“ROI 怎么算”归一出动作“解释”，并识别指标“ROI”。

### 10.4 排查

- 标准词：排查
- 词类：动作
- 别名：诊断、定位、查原因、看问题、找原因
- 定义：针对异常或问题收集证据并给出可能原因和下一步建议。
- 归一化规则：“帮我查为什么没回传”归一出动作“排查”。

### 10.5 生成报告

- 标准词：生成报告
- 词类：动作
- 别名：出报告、汇总、整理结论、写分析
- 定义：把查询、对比或排查结果组织为可阅读的报告。
- 归一化规则：“整理一份昨天投放分析”归一出动作“生成报告”。

### 10.6 准备联调

- 标准词：准备联调
- 词类：动作
- 别名：联调准备、接入准备、对接准备、开测前检查
- 定义：在广告归因、回传、事件上报或媒体接入前确认必要信息和检查项。
- 归一化规则：“要接巨量付费回传，需要准备什么”归一出动作“准备联调”。

## 11. 常见组合归一化

| 用户说法 | 标准归一化 | 备注 |
| --- | --- | --- |
| 巨量昨天消耗 | 媒体=巨量引擎；时间=昨天；指标=广告消耗；动作=查询 | 如未指定应用，需要根据上下文确认 |
| 抖音首日回收 | 媒体=巨量引擎；指标=首日 ROI 或首日收入 | 如果是百分比，归一为首日 ROI；如果是金额，归一为首日收入 |
| 这个计划不起量 | 对象=广告计划；问题类型=起量困难；动作=排查 | 需要计划 ID 或计划名称 |
| 素材点击低 | 对象=创意；指标=点击率；问题类型=点击率偏低 | “点击低”通常不是点击量低，需结合展示量确认 |
| 付费没传过去 | 事件=付费；链路=深度回传；问题类型=回传失败 | 需要媒体和样例用户 |
| 媒体和内部 ROI 对不上 | 指标=ROI；问题类型=数据差异；对比对象=媒体后台与内部报表 | 需要时间窗口和收入口径 |
| 新增掉了 | 指标=激活量；问题类型=指标下降 | 如果业务语境是注册，则应追问 |
| CPA 高了 | 指标=激活成本或指定转化成本；问题类型=成本升高 | 需要确认 CPA 对应事件 |
| 次留不好 | 指标=次日留存率；问题类型=留存偏低 | 需要对比基准 |
| 回传返回 400 | 链路=回传；对象=媒体回执；问题类型=回传失败 | 需要具体媒体和返回内容 |

## 12. 禁止归一化清单

以下词不应在缺少上下文时强行归一：

| 原词 | 禁止原因 | 应追问 |
| --- | --- | --- |
| 转化 | 可能是激活、注册、付费、留存或自定义事件 | 你说的转化具体指哪个事件？ |
| 成本 | 可能是广告消耗、激活成本、注册成本、付费成本 | 你要看总花费，还是某个转化的单价？ |
| 回收 | 可能是收入金额，也可能是 ROI | 你说的回收是金额还是回收率？ |
| 收入 | 可能是首日、累计、归因、订单或媒体侧收入 | 要看哪个时间窗口和哪种收入口径？ |
| 渠道 | 可能指广告媒体、下载渠道、自然渠道或业务渠道 | 这里的渠道指广告媒体吗？ |
| 用户 | 可能指设备、账号、角色或归因用户 | 你要按哪种用户标识查询？ |
| 数据不对 | 问题对象不明确 | 要和哪个系统或报表对比？ |
| 今天 | 需要结合时区和数据刷新规则 | 是按北京时间今天，还是媒体后台展示的今天？ |
