## 一、基本规则

- **中文注释为主，变量名用英文**
- **TypeScript strict 模式**，所有类型显式声明
- **分层清晰**：API → Service → Repository → Model
- **配置驱动**，不硬编码业务参数
- **新功能优先写测试**
- **所有文件 UTF-8 编码（无 BOM）**

## 五、错误处理

```typescript
// ✅ 正确：自定义错误类型，携带业务上下文
class CollectorError extends Error {
  constructor(
    message: string,
    public readonly sourceId: string,
    public readonly sourceName: string,
    public readonly cause?: unknown,
  ) {
    super(`[${sourceName}] ${message}`);
    this.name = 'CollectorError';
  }
}

// ✅ 正确：错误日志包含上下文
try {
  await collector.collect(source);
} catch (error) {
  logger.error('采集失败', {
    sourceId: source.id,
    sourceName: source.name,
    accessMethod: source.accessMethod,
    error: error instanceof Error ? error.message : String(error),
  });
  await this.registry.markFailure(source.id, error);
}

// ❌ 错误：吞掉异常
try {
  await collector.collect(source);
} catch {
  // 什么都不做 ← 绝对不允许
}
```

### 7.5 编码检查脚本

```javascript
// scripts/check-encoding.mjs
import { execSync } from 'child_process';
import { readdirSync, statSync } from 'fs';
import { join } from 'path';

function checkEncoding(dir) {
  const errors = [];
  
  function walk(currentDir) {
    const entries = readdirSync(currentDir);
    for (const entry of entries) {
      const fullPath = join(currentDir, entry);
      const stat = statSync(fullPath);
      
      if (stat.isDirectory()) {
        if (entry === 'node_modules' || entry === '.git') continue;
        walk(fullPath);
      } else if (/\.(ts|js|json|md|yaml|yml)$/.test(entry)) {
        try {
          const result = execSync(`file --mime-encoding "${fullPath}"`, {
            encoding: 'utf8',
          }).trim();
          
          if (!result.includes('utf-8') && !result.includes('ascii')) {
            errors.push(fullPath);
          }
        } catch {
          // Windows 可能没有 file 命令，跳过
        }
      }
    }
  }
  
  walk(dir);
  return errors;
}

const errors = checkEncoding('src');
if (errors.length > 0) {
  console.error('以下文件不是 UTF-8 编码：');
  errors.forEach(f => console.error(`  ${f}`));
  process.exit(1);
} else {
  console.log('✅ 所有文件编码检查通过');
}
```

## 九、Git 规范

### 9.1 提交信息格式

```
<type>(<scope>): <subject>

type:
  feat     新功能
  fix      修复 bug
  docs     文档变更
  style    代码格式（不影响功能）
  refactor 重构
  test     测试
  chore    构建/工具

scope:
  seed       种子系统
  collector  采集层
  extract    抽取层
  signal     信号处理
  api        API 层
  ui         前端
  config     配置
  deploy     部署

示例:
  feat(seed): 实现实体种子评分算法
  fix(collector): 修复 RSS 采集器超时重试问题
```
