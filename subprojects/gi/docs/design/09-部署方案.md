## 二、开发环境

### 2.1 前置条件

```bash
# 必需
Node.js >= 18
npm >= 9
Python >= 3.10
Docker >= 24

# 可选（本地安装，Docker 方案不需要）
Tesseract OCR (apt install tesseract-ocr / brew install tesseract)
Chromium (npx playwright install chromium)
```

### 2.2 启动步骤

```bash
# 1. 克隆仓库
cd subprojects/gi

# 2. 安装依赖
npm install

# 3. 复制环境变量
cp .env.example .env
# 编辑 .env 填入 API Key 等

# 4. 启动 Docker 服务
docker-compose up -d rsshub wewe-rss changedetection

# 5. 启动 Crawl4AI sidecar
cd src/python && python server.py &

# 6. 启动 GI 后端
npm run dev
# 服务运行在 http://localhost:8003
```

### 2.3 环境变量

```bash
# .env（开发环境）
PORT=8003
NODE_ENV=local

# Dataki
DATAKI_BASE_URL=
DATAKI_API_KEY=

# LLM
QWEN_API_KEY=
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1

# 外部服务
RSSHUB_URL=http://localhost:1200
WEWE_RSS_URL=http://localhost:4000
CHANGEDETECTION_URL=http://localhost:5000
CRAWL4AI_URL=http://localhost:8888
```

## 三、Docker Compose（生产）

### 3.1 完整 docker-compose.yml

```yaml
version: '3.8'

services:
  # ===== GI 后端 =====
  gi-backend:
    build:
      context: .
      dockerfile: Dockerfile
    ports:
      - '8003:8003'
    environment:
      PORT: 8003
      NODE_ENV: production
      QWEN_API_KEY: ${QWEN_API_KEY}
      QWEN_BASE_URL: ${QWEN_BASE_URL}
      DATAKI_BASE_URL: ${DATAKI_BASE_URL}
      DATAKI_API_KEY: ${DATAKI_API_KEY}
      RSSHUB_URL: http://rsshub:1200
      WEWE_RSS_URL: http://wewe-rss:4000
      CHANGEDETECTION_URL: http://changedetection:5000
      CRAWL4AI_URL: http://crawl4ai:8888
    volumes:
      - gi_data:/app/data          # SQLite 数据库
    depends_on:
      - rsshub
      - crawl4ai
    restart: always

  # ===== Crawl4AI Python sidecar =====
  crawl4ai:
    build:
      context: ./src/python
      dockerfile: Dockerfile
    ports:
      - '8888:8888'
    environment:
      - TESSDATA_PREFIX=/usr/share/tesseract-ocr/5/tessdata
    restart: always

  # ===== RSSHub =====
  rsshub:
    image: diygod/rsshub:latest
    ports:
      - '1200:1200'
    environment:
      NODE_ENV: production
      CACHE_TYPE: memory
      CACHE_EXPIRE: 300
      REQUEST_RETRY: 3
      REQUEST_TIMEOUT: 30000
    volumes:
      - rsshub_data:/data
    restart: always

  # ===== WeWe RSS =====
  wewe-rss:
    image: cooderl/wewe-rss:latest
    ports:
      - '4000:4000'
    environment:
      DATABASE_URL: 'sqlite:/data/wewe.db'
    volumes:
      - wewe_data:/data
    restart: always

  # ===== changedetection.io =====
  changedetection:
    image: ghcr.io/dgtlmoon/changedetection.io:latest
    ports:
      - '5000:5000'
    volumes:
      - changedetection_data:/data
    environment:
      BASE_URL: 'http://localhost:5000'
      PLAYWRIGHT_DRIVER_URL: 'ws://playwright-chrome:3000'
    restart: always

  # ===== Playwright Chrome（changedetection 可选依赖）=====
  playwright-chrome:
    image: browserless/chrome:latest
    restart: always

volumes:
  gi_data:
  rsshub_data:
  wewe_data:
  changedetection_data:
```

### 3.2 启动

```bash
# 启动所有服务
docker-compose up -d

# 查看状态
docker-compose ps

# 查看日志
docker-compose logs -f gi-backend

# 停止
docker-compose down

# 重建
docker-compose up -d --build
```

## 四、Dockerfile

### 4.1 GI 后端 Dockerfile

```dockerfile
# Dockerfile
FROM node:18-slim

WORKDIR /app

# 安装依赖
COPY package*.json ./
RUN npm ci --only=production

# 复制源码
COPY . .

# 构建（可选，如果直接用 tsx 运行则不需要）
# RUN npm run build

# 暴露端口
EXPOSE 8003

# 启动
CMD ["npm", "run", "start"]
```

### 4.2 Crawl4AI Dockerfile

```dockerfile
# src/python/Dockerfile
FROM python:3.11-slim

WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    tesseract-ocr \
    tesseract-ocr-chi-sim \
    tesseract-ocr-eng \
    && rm -rf /var/lib/apt/lists/*

# 安装 Python 依赖
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制源码
COPY . .

EXPOSE 8888

CMD ["python", "server.py"]
```

## 五、数据备份

### 5.1 SQLite 备份

```bash
#!/bin/bash
# scripts/backup.sh

TIMESTAMP=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="./backups"
DB_PATH="./data/gi.db"

mkdir -p $BACKUP_DIR

# SQLite 在线备份（不锁库）
sqlite3 $DB_PATH ".backup '$BACKUP_DIR/gi_$TIMESTAMP.db'"

# 压缩
gzip $BACKUP_DIR/gi_$TIMESTAMP.db

# 保留最近 7 天的备份
find $BACKUP_DIR -name "gi_*.db.gz" -mtime +7 -delete

echo "Backup completed: gi_$TIMESTAMP.db.gz"
```

### 5.2 定时备份

```bash
# crontab -e
# 每天凌晨 2 点备份
0 2 * * * /path/to/gi/scripts/backup.sh >> /var/log/gi-backup.log 2>&1
```

## 六、监控与告警

### 6.1 健康检查

```typescript
// GI 内部健康检查端点
app.get('/health', async (req, res) => {
  const checks = {
    database: await checkDatabase(),
    rsshub: await checkExternalService(process.env.RSSHUB_URL),
    crawl4ai: await checkExternalService(process.env.CRAWL4AI_URL),
    llm: await checkLLMHealth(),
  };

  const allOk = Object.values(checks).every(c => c.status === 'ok');
  
  res.status(allOk ? 200 : 503).json({
    status: allOk ? 'healthy' : 'degraded',
    checks,
    uptime: process.uptime(),
  });
});
```

### 6.2 日志

```typescript
// 日志级别
// - error: 错误日志（采集失败、LLM 调用失败等）
// - warn: 警告（源降级、种子淘汰等）
// - info: 信息（采集成功、事件抽取完成等）
// - debug: 调试（详细请求/响应）

// 日志格式
{
  "timestamp": "2026-06-18T10:30:00Z",
  "level": "info",
  "module": "collector",
  "message": "采集完成",
  "context": {
    "sourceId": "uuid",
    "sourceName": "GameLook",
    "evidenceCount": 12,
    "newEvidenceCount": 8,
    "duration": 3500
  }
}
```

### 6.3 告警规则

| 场景 | 告警方式 | 条件 |
|------|---------|------|
| 源下线 | 日志 + 通知 | 连续 3 次采集失败 |
| LLM 调用失败 | 日志 | 连续 5 次失败 |
| Cookie 过期 | 通知 | WeWe RSS 健康检查失败 |
| 数据库异常 | 日志 + 通知 | 查询失败 |
| 漏采率过高 | 通知 | 搜索兜底发现 > 20% 遗漏 |
