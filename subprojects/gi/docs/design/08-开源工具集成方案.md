## 二、RSSHub

> 万物皆可 RSS。把不支持 RSS 的网站变成 RSS 源。

### 2.1 部署

```yaml
# docker-compose.yml
services:
  rsshub:
    image: diygod/rsshub:latest
    restart: always
    ports:
      - '1200:1200'
    environment:
      NODE_ENV: production
      # 反爬配置
      PROXY_PROTOCOL: ''
      PROXY_HOST: ''
      PROXY_PORT: ''
      # 缓存
      CACHE_TYPE: memory
      CACHE_EXPIRE: 300
      # 限流
      REQUEST_RETRY: 3
      REQUEST_TIMEOUT: 30000
    volumes:
      - rsshub_data:/data
```

### 2.2 GI 使用的 RSS 路由

| 路由 | 说明 | 对应源 |
|------|------|--------|
| `/taptap/hot/overview` | TapTap 热门 | TapTap 热门游戏 |
| `/taptap/app/:id/events` | TapTap 游戏动态 | 具体游戏 |
| `/weibo/user/:uid` | 微博用户 | KOL/游戏官方 |
| `/bilibili/user/dynamic/:uid` | B站用户动态 | 游戏UP主 |
| `/nga/forum/:fid` | NGA 论坛板块 | 游戏社区 |
| `/steam/news/:appid` | Steam 游戏新闻 | Steam 游戏 |
| `/gamelook` | GameLook 文章 | 行业媒体 |

### 2.3 集成方式

```typescript
// GI 通过 RSS 采集器直接读取 RSSHub 生成的 feed
const source: IntelSource = {
  name: 'TapTap-热门',
  sourceType: 'community',
  accessMethod: 'rss',
  baseUrl: 'http://rsshub:1200',
  feedUrl: 'http://rsshub:1200/taptap/hot/overview',
  schedule: { cron: '*/15 * * * *' },
};
```

## 三、WeWe RSS

> 基于微信读书的公众号 RSS 生成器。

### 3.1 部署

```yaml
# docker-compose.yml
services:
  wewe-rss:
    image: cooderl/wewe-rss:latest
    restart: always
    ports:
      - '4000:4000'
    environment:
      DATABASE_URL: 'sqlite:/data/wewe.db'
      # 微信读书 Cookie（需要手动登录获取）
      # Cookie 过期后需要重新获取
    volumes:
      - wewe_data:/data
```

### 3.2 使用方式

```
1. 部署 WeWe RSS
2. 在 WeWe RSS 管理页面登录微信读书
3. 添加关注的公众号
4. WeWe RSS 自动将公众号文章转为 RSS feed
5. GI 通过 RSS 采集器读取 feed
```

### 3.3 GI 集成

```typescript
const source: IntelSource = {
  name: '公众号-游戏葡萄',
  sourceType: 'wechat_mp',
  accessMethod: 'rss',
  baseUrl: 'http://wewe-rss:4000',
  feedUrl: 'http://wewe-rss:4000/feeds/游戏葡萄.xml',
  schedule: { cron: '0 */2 * * *' },  // 每 2 小时
};
```

### 3.4 Cookie 管理

> WeWe RSS 的 Cookie 会过期，需要监控和提醒

```typescript
// 定期检查 WeWe RSS 健康状态
async function checkWeWeHealth(): Promise<void> {
  try {
    const response = await fetch('http://wewe-rss:4000/health');
    if (!response.ok) {
      notify('WeWe RSS 可能 Cookie 过期，请检查');
    }
  } catch {
    notify('WeWe RSS 不可达');
  }
}
```

## 四、changedetection.io

> 网页变更监控。用于监控版号公告、榜单变化等。

### 4.1 部署

```yaml
# docker-compose.yml
services:
  changedetection:
    image: ghcr.io/dgtlmoon/changedetection.io:latest
    restart: always
    ports:
      - '5000:5000'
    volumes:
      - changedetection_data:/data
    environment:
      BASE_URL: 'http://localhost:5000'
      # 如果使用 Playwright 浏览器
      PLAYWRIGHT_DRIVER_URL: 'ws://playwright-chrome:3000'

  # 可选：Playwright 浏览器支持（用于 JS 渲染页面）
  playwright-chrome:
    image: browserless/chrome:latest
    restart: always
```

### 4.2 监控目标

| 监控页面 | 选择器 | 频率 | 用途 |
|---------|--------|------|------|
| 国家新闻出版署-版号公告 | `#list` | 每天 2 次 | 版号下发监控 |
| App Store 畅销榜 | `.chart-table` | 每 4 小时 | iOS 榜单变化 |
| Google Play 畅销榜 | `.srQWpb` | 每 4 小时 | Android 榜单变化 |
| Steam 热门新品 | `.popular_new_releases` | 每 6 小时 | Steam 新品监控 |

### 4.3 集成方式

```
changedetection.io 检测到变更 →
  Webhook 通知 GI →
    GI 创建 CollectionJob →
      采集变更内容 →
        进入 LLM 抽取流程
```

```typescript
// GI 接收 changedetection.io 的 Webhook
app.post('/api/v1/webhooks/changedetection', async (req, res) => {
  const { watchUuid, watchName, watchUrl, snapshotUrl } = req.body;
  
  // 创建采集任务
  const job = await createCollectionJob({
    sourceId: findSourceByWatchName(watchName),
    trigger: 'webhook',
    metadata: { watchUuid, snapshotUrl },
  });
  
  res.json({ success: true, jobId: job.id });
});
```

## 五、Crawl4AI

> 静态页采集 + OCR。通过 Python sidecar 提供服务。

### 5.1 部署

```
Crawl4AI 运行在 Python 环境中：
- 开发环境：本地 Python（python server.py）
- 生产环境：Docker 容器

启动命令：cd src/python && python server.py
默认端口：8888
```

### 5.2 Python sidecar 接口

```python
# src/python/server.py
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class CrawlRequest(BaseModel):
    urls: list[str]
    options: dict = {}

@app.post("/crawl")
async def crawl(request: CrawlRequest):
    results = []
    for url in request.urls:
        result = await crawl_page(url, request.options)
        results.append(result)
    return {"results": results}

@app.post("/ocr")
async def ocr(image_url: str):
    """单独 OCR 接口"""
    text, confidence = await extract_text(image_url)
    return {"text": text, "confidence": confidence}

@app.get("/health")
async def health():
    return {"status": "ok"}
```

### 5.3 GI 调用方式

```typescript
// GI 通过 Crawl4AI 采集器调用 Python sidecar
const sidecarUrl = process.env.CRAWL4AI_URL || 'http://localhost:8888';

const response = await fetch(`${sidecarUrl}/crawl`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    urls: ['https://example.com/article/1'],
    options: {
      ocr: true,
      extractImages: true,
    },
  }),
});
```

## 六、Playwright

> 动态页采集。需要 JS 渲染的页面。

### 6.1 安装

```bash
# 安装 Playwright 和浏览器
npm install playwright
npx playwright install chromium
```

### 6.2 使用场景

```typescript
// 在 PlaywrightCollector 中使用
import { chromium } from 'playwright';

class PlaywrightCollector implements Collector {
  private browser: Browser | null = null;

  private async getBrowser(): Promise<Browser> {
    if (!this.browser) {
      this.browser = await chromium.launch({
        headless: true,
        args: ['--no-sandbox', '--disable-setuid-sandbox'],
      });
    }
    return this.browser;
  }
}
```

### 6.3 资源控制

```yaml
playwright:
  max_concurrent_pages: 3     # 最多同时 3 个页面
  browser_reuse: true         # 复用 browser 实例
  page_timeout: 60000         # 页面超时 60s
  navigation_timeout: 30000   # 导航超时 30s
```

## 七、Tesseract OCR

> 开源 OCR 引擎。Crawl4AI 内置集成。

### 7.1 集成方式

```
Crawl4AI 自动调用 Tesseract 进行 OCR
GI 不需要直接调用 Tesseract
只需在 Crawl4AI 请求中设置 ocr: true
```

### 7.2 中文优化

```python
# Crawl4AI Python sidecar 中的 OCR 配置
import pytesseract

def extract_text(image):
    # 使用中文 + 英文模型
    text = pytesseract.image_to_string(image, lang='chi_sim+eng')
    return text
```

## 八、Qwen API（通义千问）

> LLM 服务。用于事件抽取、种子扩展、图片理解。

### 8.1 API 配置

```bash
# .env
QWEN_API_KEY=your-api-key
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

### 8.2 使用的模型

| 用途 | 模型 | 说明 |
|------|------|------|
| 事件抽取 | qwen-plus | 性价比最优 |
| 种子扩展 | qwen-max | 需要创造性 |
| 图片理解 | qwen-vl-max | 视觉理解能力 |

### 8.3 限流管理

```yaml
# src/config/llm.yaml
llm:
  rate_limit:
    requests_per_minute: 30
    requests_per_day: 1000
    # 按模型独立限流
    by_model:
      qwen-plus:
        rpm: 30
      qwen-max:
        rpm: 10
      qwen-vl-max:
        rpm: 20
```

## 十二、故障排查

### 12.1 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| RSSHub 某个路由返回空 | 源站反爬升级 | 检查 RSSHub 日志，更新路由配置 |
| WeWe RSS Cookie 过期 | 微信读书 Cookie 有效期约 30 天 | 重新登录获取 Cookie |
| Crawl4AI OCR 准确率低 | 图片质量差/字体特殊 | 升级到 Qwen-VL 理解 |
| Playwright 超时 | 页面加载慢 | 增加超时时间/检查网络 |
| changedetection.io 误报 | 页面广告/时间戳变化 | 调整 CSS 选择器排除噪音 |

### 12.2 健康检查端点

```typescript
// GI 启动时检查所有依赖服务
async function checkDependencies(): Promise<void> {
  const checks = [
    { name: 'RSSHub', url: 'http://rsshub:1200/healthcheck' },
    { name: 'WeWe RSS', url: 'http://wewe-rss:4000/health' },
    { name: 'Crawl4AI', url: 'http://localhost:8888/health' },
    { name: 'changedetection', url: 'http://changedetection:5000/api/v1/auth' },
  ];

  for (const check of checks) {
    try {
      const res = await fetch(check.url, { signal: AbortSignal.timeout(5000) });
      console.log(`✅ ${check.name}: OK`);
    } catch {
      console.warn(`❌ ${check.name}: 不可达`);
    }
  }
}
```
