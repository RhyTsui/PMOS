# 小乔智投字体字重字号字色遍历

# 目标：遍历当前项目的字重 字体 字号 字色值  然后提炼出优化建议，目标是统一规范 

已遍历当前项目中与前端样式相关的文件，统计口径重点放在：

*   frontend/src/src/\*\*/\*.css|tsx|ts|jsx|js
    
*   跳过：node\_modules、.next、dist、build、coverage、imported
    

结论：当前项目已经有基础 token，但组件内仍大量硬编码字号、字重、字色，尤其集中在后台页和局部业务组件，建议收敛为一套  「语义化字体规范」。

## 7. 落地建议

优先级建议如下：

1.  先收敛 token
    
    *   在 globals.css 中建立唯一字体、字号、字重、字色 token。
        
    *   AntdProvider.tsx 改为引用同一套语义值。
        
2.  再治理高频页面
    
    *   优先处理 admin/page.tsx、WorkflowManagementTab.tsx、ChatContainer.tsx。
        
    *   把 text-\[#xxxxxx\] 改为 text-\[var(--color-text-xxx)\] 或封装类名。
        
3.  限制任意值
    
    *   禁止新增 text-\[13.5px\]、fontWeight: 650、text-\[#xxxxxx\]。
        
    *   只允许特殊视觉稿场景使用任意值，并加注释说明。
        
4.  建立组件语义类
    
    *   .ui-title
        
    *   .ui-subtitle
        
    *   .ui-body
        
    *   .ui-caption
        
    *   .ui-meta
        
    *   .ui-muted
        
5.  加入检查规则
    
    *   ESLint / Stylelint 中限制：
        
        *   fontWeight: 650
            
        *   text-\[#
            
        *   font-size: 13px
            
        *   text-\[10px\]
            
        *   组件内直接写 #xxxxxx
            

总体判断：项目当前不是没有规范，而是“规范存在但没有成为唯一入口”。下一步重点不是新增更多颜色或字号，而是把现有硬编码全  部迁移到一套语义 token。

## 8. 实施落地补充（2026-05-27）

本次已按本文规范完成第一阶段代码落地，重点不是一次性清空所有历史硬编码，而是建立唯一入口、收敛重点区域，并把新增样式纳入门禁。

### 8.1 Label / Caption / Body 规范

| 语义 | 类名 | 字号 | 行高 | 字重 | 字间距 | 用途 |
|---|---|---:|---:|---:|---:|---|
| Body | `.ui-body` | 14px | 22px | 400 | 0 | 正文、表单说明、常规内容 |
| Label | `.ui-label` | 12px | 18px | 500 | 0 | 字段名、分组标签、次级按钮、强调型短标签 |
