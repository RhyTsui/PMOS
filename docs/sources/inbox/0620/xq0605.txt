总纲补充：
小乔 Chat 的能力来源不是单一大模型，而是：内部知识库、外部联网搜索、业务 MCP、文件/表格、自动化任务和大模型认知增强的组合。

架构原则：
模型负责理解、归纳、解释和草拟；
MCP 负责业务事实和执行；
Web Search 负责外部实时公开信息；
知识库负责内部沉淀知识；
Artifact/Task 负责交付和追踪；
Trace 负责旁路观测，不影响主流程。   

产品原则：
通用 Chat 负责理解用户目标；
Capability Discovery 负责发现能做什么；
Resolver Chain 负责把自然语言实体转成工具参数；
Tool Contract 负责判断能不能执行；
Execution Policy 负责决定调用哪个、是否 fallback；
MCP 负责真实业务动作；
LLM 负责解释、总结、诊断和草拟；
Evidence Ledger 负责可追溯；
Presentation 负责主消息和右侧分层展示。
