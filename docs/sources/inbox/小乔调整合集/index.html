6 个当前形态

基础状态

适合默认空闲、普通陪伴、页面常驻入口、没有明确任务状态时使用。

默认 / 常驻

打瞌睡

适合长时间无操作、用户离开一会儿、低活跃等待、深夜模式里的轻松反馈。

空闲 / 低活跃

等待气泡

适合请求处理中、加载中、正在思考、排队等待、模型生成结果前的状态。

加载 / 思考中

收到全部结果

适合任务完成、全部结果返回、同步成功、生成完成、可查看最终内容时使用。

完成 / 惊喜

认真分析

适合检索资料、推理分析、读取文件、分析数据、处理复杂问题时使用。

检索 / 分析

遇到错误

适合失败、异常、结果不可用、需要用户重试或重新确认输入时使用。

错误 / 重试
