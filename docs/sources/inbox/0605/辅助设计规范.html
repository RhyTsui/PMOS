🖱️ 交互规范

可点击元素规范

设计原则：所有可点击元素必须有明确的视觉反馈，包括悬停状态、激活状态和禁用状态

状态 视觉效果 时长
默认 原始样式 -
悬停 (Hover) 背景色变化 + 阴影增强 0.2s ease
激活 (Active) 颜色加深 + 位移-1px 0.1s ease
焦点 (Focus) 2px蓝色光圈 0.15s ease
禁用 (Disabled) 透明度60% + 不可点击 -

过渡动画

/* 标准过渡效果 */ transition: all 0.2s ease; /* 快速过渡（悬停效果）*/ transition: all 0.15s ease; /* 慢速过渡（大型组件）*/ transition: all 0.3s ease; /* 禁用过渡（性能优化）*/ @media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }

📋 使用指南

适用场景

✅ 推荐使用

  • 企业后台管理系统
  • 数据分析平台
  • SaaS产品仪表盘
  • 高科技风格Web应用
  • 响应式管理界面

❌ 不推荐使用

  • 娱乐类应用（风格过于正式）
  • 儿童产品（缺乏趣味性）
  • 创意作品展示（风格受限）
  • 深色模式为主的产品

实施建议

1. 优先级：先实现色彩系统和字体规范，再逐步应用组件样式

2. 定制化：可根据品牌需求调整主色调，但保持中性色不变

3. 响应式：侧边栏在移动端可折叠，内容区自适应宽度

4. 无障碍：确保颜色对比度符合WCAG AA标准（4.5:1）
