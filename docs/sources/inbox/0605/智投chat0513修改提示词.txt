一、整体布局结构
Chat.DeepSeek 的布局采用三栏式结构，简洁且高效：

text
┌─────────────────────────────────────────────────────────────┐
│                         顶部栏                               │
├─────────────┬─────────────────────────────────┬─────────────┤
│             │                                 │             │
│   左侧边栏   │          主聊天区域              │   右侧边栏   │
│  (对话列表)  │        (消息流 + 输入框)          │  (动态面板)  │
│             │                                 │  (可选)     │
│             │                                 │             │
└─────────────┴─────────────────────────────────┴─────────────┘
各区域功能说明
左侧边栏：

新建对话按钮（视觉突出）

历史对话列表（按时间倒序）

对话搜索/筛选入口

用户头像/设置入口（底部）

主聊天区域：

消息流容器（滚动区域）

输入框组件（底部固定）

欢迎语/空白状态

消息气泡（区分用户/AI）

右侧边栏（可折叠）：
模型信息

系统配置

联网搜索开关

上下文长度设置

四、交互体验要点
流式输出
使用 SSE 或 Fetch API ReadableStream 实现逐字输出：

效果：AI 回复像打字一样逐字显示

感知等待时间从 2.3 秒降至 0.8 秒

配合"正在输入..."动画提升体验

滚动行为
新消息自动滚动到底部

用户向上滚动查看历史时不自动滚动（尊重用户意图）

提供"回到底部"浮动按钮

快捷功能
提供 4-6 个快捷提示词卡片：

解释概念、总结文本、翻译、写代码、润色文案

点击后自动填入输入框（非直接发送）

支持自定义快捷指令

响应式反馈
操作	反馈
发送消息	立即显示用户气泡，开始加载动画
AI响应	流式输出，逐字显示
网络错误	Toast提示 + 重试按钮
复制代码	代码块右上角出现"复制"按钮，点击反馈"已复制"
