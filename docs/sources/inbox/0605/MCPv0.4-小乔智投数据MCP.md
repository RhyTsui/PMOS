MCPv0.4-小乔智投数据MCP
背景与目标：广告业务数据统一采用开放平台受控调用，用于广告数据查询诊断

需求一.多维广告Tool权限分配
对象：
平台：开放平台-MCP中心
服务：小乔智投MCP
工具：多维tool
报表：广告域
用户：小闪用户

需求说明：
智投用户默认拥有已分配项目的多维广告域tool的数据权限，魔方后台分配问数MCP权限不变。
业务流程：
1.新建小乔智投MCP
2.智投tool发布后自动同步到小乔智投MCP
3.多维广告域tool发布后自动同步到小乔智投MCP
4.筛选每个项目的“魔方MCP的多维广告域tool”
5.获取智投每个项目最新的用户列表并绑定权限
验收标准：
1.开放平台给小乔智投分配大模型密钥、小乔智投MCP密钥
2.小乔智投调用MCP，传智投用户ID和项目ID，可获取智投tool、多维广告域tool数据。

需求二、智能体权限分配
对象：
平台：开放平台-MCP中心
服务：小乔MCP
工具：魔方Tool
报表：日周月报
维度：渠道-渠道分类-官方
用户：小乔智投Agent

需求说明：
小乔智投Agent在排查数据问题时，可查询魔方广告项目的官方渠道数据，对比验证计算是否正常。
业务流程：
1.新建小乔智投Agent
2.新建小乔MCP
3.获取智投项目列表
4.给小乔MCP自动分配广告项目的魔方MCP的日报tool权限，且仅限官方渠道查询。
5.给小乔MCP自动分配小乔智投MCP的全部tool权限。
6.给小乔智投Agent分配小乔MCP权限
验收标准：
1.开放平台给小乔智投分配小乔MCP密钥
2.小乔智投Agent调用MCP，传AgentID、项目ID、官方渠道ID，可获取智投tool、多维广告域tool数据、魔方广告项目的官方渠道日报tool数据。

开发建议方案：
业务流程：
1.暂不做智能体权限管理，由智投控制权限调用，开放平台审计。
2.获取智投项目列表
3.给小乔智投MCP自动分配广告项目的魔方MCP的日报tool权限，可按渠道ID查询。

验收标准：
1.小乔智投调用MCP，传项目ID、渠道ID，可获取智投tool、多维广告域tool数据、魔方广告项目的渠道日报tool数据。
