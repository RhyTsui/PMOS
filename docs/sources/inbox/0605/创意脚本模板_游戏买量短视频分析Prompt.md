# 游戏买量短视频创意脚本分析 — 大模型Prompt模板

## 使用方法
将下方"System Prompt"完整复制到大模型的系统提示词/角色设定中，然后上传视频关键帧截图（建议每1-2秒截一帧）或提供视频链接，大模型将按固定模板输出标准化创意脚本。

### 二、创意脚本（标准化分镜表）

先写一句整体结构描述，如："8个'人格测试结果页'循环展示，每种人格2秒"

然后输出分镜表：

| 镜号 | 时长 | 画面内容 | 文案 | 视觉特效 | 音效/音乐 | 转场方式 |
|:---:|:---:|----------|------|----------|-----------|----------|
| [编号] | [时间范围] | [角色/场景/动作/表情的详细描述] | [顶部标题/人格类型/标签/台词/底部数据的完整文案] | [背景风格/角色风格/撞色/特效/标识] | [音效类型和情绪] | [Cut/淡入淡出/滑动等] |

**分镜表填写要求**：
- 画面内容：必须具体到角色造型、服装配色、道具、动作、表情，不要只写"角色出现"
- 文案：完整抄录画面中出现的一切文字，包括标题、标签、台词、数据
- 视觉特效：描述背景风格、角色美术风格、配色方案、特殊视觉效果
- 每个镜头的描述要让没看过视频的人也能想象出画面

## 分析原则
1. 所有分析必须基于视频实际内容，不要泛泛而谈
2. 配色必须给出具体HEX值，不能只说"蓝色""绿色"
3. 分镜表的画面描述要具体到可以凭文字复现画面
4. 创意公式必须可复用，不能只适用于这一个视频
5. 设计师视角的输出要让设计师看了能直接执行
6. 导演视角的输出要让导演看了能判断这个创意值不值得抄、怎么抄

## 使用建议

1. **关键帧截图**：建议每1-2秒截一帧，竖屏视频截全屏，横屏视频截关键画面
2. **音频信息**：大模型无法听音频，建议在对话中补充说明BGM类型、音效节奏、是否有配音
3. **视频链接**：部分模型支持解析视频链接，但关键帧截图的精度更高
4. **多视频对比**：可以同时上传多个视频要求对比分析，Prompt模板同样适用
5. **迭代优化**：如果输出质量不够，可以在Prompt中增加你关注的特定维度（如"重点分析转场节奏"）
