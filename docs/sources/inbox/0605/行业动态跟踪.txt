## 任务目标

本 Skill 用于自动化构建行业研究信息源库，实现从公司/产品/从业者三个维度持续采集、结构化分析和报告生成。

**核心能力：**
- 行业边界拆解（MECE原则）：子行业、产业链、应用场景三维建模
- 公司标签化采集：按维度打标签，支持精准筛选
- Top 产品名单获取与技术参数采集
- 从业者挖掘与社媒账号推理
- 关键词地图与行话挖掘
- 多维度搜索矩阵与智能降噪
- 信源质量评估与动态调整
- 结构化内容分析与横向对比

**触发条件：**
- 用户需要进行行业调研、竞品分析
- 用户需要构建行业信息采集系统
- 用户需要挖掘某行业的关键公司和从业者

## 【深度增强功能】🚀 v2.0

### 步骤 1 增强：行业边界拆解（MECE原则）

**目标**：避免定义过宽，将行业拆解为多个子维度。

**新增参数**：
```bash
python scripts/main.py init \
  --industry "低空经济" \
  --purpose "产品规划调研" \
  --content "技术架构、成本结构、竞争格局" \
  --keywords "eVTOL,无人机,低空物流" \
  --subsectors "整机制造,核心零部件,基础设施,运营服务" \
  --chains "研发,生产,测试,运营" \
  --scenes "城市物流,应急救援,农业植保,测绘巡检"
```

**输出**：
- `meta.json` 中新增 `subsectors`、`chains`、`scenes` 字段
- `references/keywords.json` 关键词库初始结构

### 步骤 2 增强：公司标签化

**目标**：按子行业、产业链环节、应用场景给公司打标签。

**新增字段**：
- `subsector`：子行业标签
- `chain_link`：产业链环节
- `scene`：应用场景

**自动归类**：通过公司简介用 NLP 自动归类，或由用户手动标注。

### 步骤 3-4 增强：关键词地图与搜索模板

**关键词库结构**：见 [references/keywords_schema.md](references/keywords_schema.md)

**搜索模板库**：见 [references/search_templates.md](references/search_templates.md)

**新增信源类型**：
- 行业协会（site:cada.org.cn）
- 监管机构（site:gov.cn）
- 学术数据库（site:cnki.net）

### 步骤 5 增强：产品级信息颗粒度

**新增字段**：
- `subsector`：子行业分类
- `certification`：认证资质
- `key_spec`：关键技术参数

### 步骤 6 增强：搜索逻辑矩阵

**多维度搜索矩阵**：
| 维度 | 关键词示例 | 搜索模板 |
|------|-----------|----------|
| 行业痛点 | 续航、安全、成本 | {关键词} 解决方案 -玩具 -入门 |
| 成本拆解 | 研发成本、制造成本 | {关键词} 占比 分析 |
| 竞争格局 | 市场份额、头部企业 | {行业} {关键词} 排名 |
| 技术路线 | 锂电池、氢燃料 | {关键词} 技术原理 发展趋势 |
| 监管动态 | 适航认证、空域管理 | site:gov.cn {关键词} 政策 |

**降噪技巧**：
- 排除词：`-广告 -推广 -招聘`
- 限定权威源：`site:gov.cn OR site:edu.cn`
- 时间过滤：`after:2023-01-01`

### 信源质量评估

**四维评估模型**：
| 维度 | 权重 | 评估指标 |
|------|------|----------|
| 权威性 | 30% | 机构背景、作者资质 |
| 时效性 | 25% | 发布时间、更新频率 |
| 准确性 | 25% | 交叉验证、数据来源 |
| 完整性 | 20% | 覆盖范围、细节深度 |

**信源分级**：A+ (90-100) / A (80-89) / B+ (70-79) / B (60-69) / C (40-59) / D (0-39)

详见：[references/source_quality.md](references/source_quality.md)

### 步骤 8：研究社媒账号推理规则

**【前置条件】**
```

```

**【执行动作】**

**【智能体必须执行的操作】**
1. 阅读 [references/inference_rules.md](references/inference_rules.md)
2. 理解推理规则类型：
   - R001: 拼音点分隔 (zhang.san)
   - R002: 拼音下划线分隔 (zhang_san)

   - R004: 英文名+姓

## 信源评分工具

### 轻量级评分（推荐）

基于三维度快速评分：更新频率（35%）+ 权威域名（40%）+ 内容一致性（25%）

```bash
# 评分单个URL
python scripts/core/lightweight_scorer.py --industry "<行业>" --url "<URL>"

# 评分所有渠道
python scripts/core/lightweight_scorer.py --industry "<行业>" --score-all

# 生成评分报告
python scripts/core/lightweight_scorer.py --industry "<行业>" --report
```

**评分等级：**
- A级（85-100）：优质信源，优先采集
- B级（70-84）：良好信源，正常采集
- C级（55-69）：一般信源，适度采集
- D级（40-54）：较差信源，谨慎使用
- E级（0-39）：低质信源，建议移除

详见：[references/lightweight_score.md](references/lightweight_score.md)

### 关键词提取

从已采集内容中自动提取和扩展关键词：

```bash
# 提取关键词
python scripts/core/keyword_extractor.py --industry "<行业>" --extract

# 查看关键词库统计
python scripts/core/keyword_extractor.py --industry "<行业>" --stats
```

## 注意事项

### 强制执行要求
- **禁止跳过步骤**：必须按 1→2→3...→17 顺序执行
- **前置校验**：每步执行前必须检查前置步骤状态
- **完成确认**：每步执行后必须输出完成标志

### 数据采集规范
- 遵守目标网站的 robots.txt 协议
- 控制请求频率，避免对目标站点造成压力
- 仅采集公开信息，不涉及隐私数据

### 智能体与脚本分工
- **脚本负责**：数据存储、网络请求、格式转换等技术性操作
- **智能体负责**：语义理解、内容分析、框架选择等认知性任务
- 充分利用智能体的语言理解和推理能力
