业务域协议（Domain Protocol）
report_query 只是第一层意图；进入报表域后，还要继续细分：趋势、汇总、排名、对比、诊断、路径等子语义；这些子语义最终决定：数据结构、能力选择、screenType、regions、componentBinding 和 UI。
Report Domain = 任务编排域 Sub Intent / Analysis View = 可组合视图，不要把问数细分做成单选意图树，要做成“主目标 + 多分析视图组合”的报表域编排模型
Top Intent：判断大方向
Report Domain：进入问数/分析域
Primary Goal：判断主目标
Analysis Views：多选组合
Execution Plan：编排多个分析块
SemanticResultContract：按 regions 展示结果
