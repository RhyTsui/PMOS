## 🎯 核心设计令牌（可直接复制使用）

```css
:root {
    /* 主色调 */
    --primary-500: #3B82F6;
    --primary-600: #2563EB;
    --primary-50: #EFF6FF;
    
    /* 中性色 */
    --gray-50: #F9FAFB;
    --gray-100: #F3F4F6;
    --gray-200: #E5E7EB;
    --gray-800: #1F2937;
    
    /* 间距 */
    --spacing-md: 16px;
    --spacing-lg: 24px;
    
    /* 圆角 */
    --radius-md: 8px;
    --radius-lg: 12px;
    
    /* 阴影 */
    --shadow-sm: 0 1px 2px 0 rgba(0,0,0,0.05);
    --shadow-md: 0 4px 6px -1px rgba(0,0,0,0.1);
    
    /* 布局 */
    --sidebar-width: 260px;
    --topnav-height: 64px;
}
```

## 📝 自定义修改指南

### 修改主色调

如果你想使用不同的主色调，只需修改 `:root` 中的 primary 颜色值：

```css
/* 例如：改为绿色主题 */
--primary-500: #10B981;  /* 绿色 */
--primary-600: #059669;
--primary-50: #ECFDF5;
```

### 修改侧边栏宽度

在CSS中全局替换：
- `260px` → 你想要的宽度（例如 `240px`）

### 修改圆角大小

调整 `--radius-*` 变量：
```css
--radius-md: 6px;  /* 改为更小的圆角 */
--radius-lg: 10px;
```
