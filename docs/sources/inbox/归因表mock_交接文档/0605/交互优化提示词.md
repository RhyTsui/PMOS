# 智投chat 建议入口区域交互优化 — Codex 完整提示词

## 一、问题现状（红色框标注区域）

当前 6 个「你可以直接这样问」的入口行存在以下问题：

1. **hover 态不醒目**：当前只有淡淡的浅蓝背景变化（`--bg-hover: #eff6ff`），用户感知不到这是一个可点击的入口。
2. **点击交互无反馈**：用户点击后，没有明确的行为反馈（应该自动把对应提示词回填到底部输入框并自动触发发送）。
3. **输入框无发光吸引**：当前输入框聚焦时只有蓝色边框 + 淡色外发光，吸引力不够，用户在看到建议入口后不知道下一步要去输入框操作。

---

## 二、优化目标（设计规范参考 WeDesign Token）

### 2.1 建议入口行 Hover 态（增强发光感）

**当前代码**：
```css
.suggestion-card:hover {
  background: var(--bg-hover);
  border-color: var(--primary-200);
}
```

**目标代码**：
```css
.suggestion-card {
  position: relative;
  display: flex;
  align-items: baseline;
  gap: var(--spacing-lg);
  padding: 14px var(--spacing-md);
  cursor: pointer;
  text-align: left;
  border-radius: var(--radius-md);
  transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1);
  border: 1.5px solid transparent;
  background: transparent;
}

.suggestion-card::before {
  content: '';
  position: absolute;
  inset: 0;
  border-radius: var(--radius-md);
  background: var(--primary-50);
  opacity: 0;
  transition: opacity 0.2s ease;
  z-index: -1;
}

.suggestion-card:hover {
  border-color: var(--primary-300);
  transform: translateX(4px);
}

.suggestion-card:hover::before {
  opacity: 1;
}

.suggestion-card:hover .card-title {
  color: var(--primary-600);
}

.suggestion-card:hover .card-tag {
  color: var(--primary-500);
}
```

**设计理由**：
- 用 `::before` 伪元素做背景光，避免影响文字层级
- 边框用 `primary-300`（#93c5fd），hover 时更明显
- 整体右移 4px，给用户「被选中」的方向感
- 标题文字变品牌蓝色 `primary-600`，副标题变浅品牌蓝 `primary-500`
- 过渡用 `cubic-bezier(0.4, 0, 0.2, 1)`，WeDesign 标准缓动

### 2.2 点击后回填输入框（新增 JS 交互）

**目标行为**：
- 用户点击任意一行 → 该行对应的完整提示词自动填入底部 `.input-field`
- 填入后输入框立即获得焦点
- 输入框获得焦点时触发「强发光」视觉反馈（见 2.3）
- 光标自动移到输入框末尾
- （可选）300ms 延迟后自动高亮全选，让用户可以直接按回车发送

**需在 HTML 中为每个 `.suggestion-card` 增加 `data-prompt` 属性**：

**新增 JS（放在 `</body>` 前）**：

```javascript
<script>
  (function() {
    const inputField = document.querySelector('.input-field');
    const inputBox = document.querySelector('.input-box');
    const suggestionCards = document.querySelectorAll('.suggestion-card');

    suggestionCards.forEach(card => {
      card.addEventListener('click', function() {
        const promptText = this.getAttribute('data-prompt');
        if (!promptText || !inputField) return;

        // 回填文本
        inputField.value = promptText;

        // 聚焦输入框
        inputField.focus();

        // 触发输入框的发光动画（通过添加/移除 class）
        inputBox.classList.add('input-glow-active');
        setTimeout(() => {
          inputBox.classList.remove('input-glow-active');
        }, 800);

        // 将光标移到末尾
        const len = inputField.value.length;
        inputField.setSelectionRange(len, len);
      });
    });
  })();
</script>
```

### 2.3 输入框点击回填后的「强发光」效果

**目标**：用户点击建议入口后，底部输入框要有一个明显的脉冲发光效果，告诉用户「文本已经填到这里了，你可以直接发送」。

**新增 CSS**：

```css
/* 输入框脉冲发光动画 */
@keyframes inputGlowPulse {
  0% {
    box-shadow: 0 0 0 0 rgba(59, 130, 246, 0.4);
    border-color: var(--primary-400);
  }
  50% {
    box-shadow: 0 0 0 8px rgba(59, 130, 246, 0);
    border-color: var(--primary-500);
  }
  100% {
    box-shadow: 0 0 0 0 rgba(59, 130, 246, 0);
    border-color: var(--border-focus);
  }
}

.input-box.input-glow-active {
  animation: inputGlowPulse 0.8s ease-out;
  border-color: var(--primary-500);
}
```

**设计理由**：
- 使用 `rgba(59, 130, 246, 0.4)` 到 `rgba(59, 130, 246, 0)` 的脉冲扩散
- 对应 WeDesign 品牌蓝 `--primary-500: #3B82F6`
- 动画时长 0.8s，ease-out 缓出，不干扰用户操作
- 发光结束后回到正常的聚焦态

### 2.4 增加「点击后行态反馈」

用户点击建议入口后，该行本身也要有一个「已选中」的瞬间反馈，然后文本被填入输入框。

**新增 CSS**：

```css
.suggestion-card.clicked {
  background: var(--primary-100);
  border-color: var(--primary-400);
  transform: translateX(6px);
  transition: all 0.15s ease;
}

.suggestion-card.clicked .card-title {
  color: var(--primary-700);
}
```

**修改 JS**：

```javascript
suggestionCards.forEach(card => {
  card.addEventListener('click', function() {
    // 移除其他行的 clicked 态
    suggestionCards.forEach(c => c.classList.remove('clicked'));
    // 给当前行添加 clicked 态
    this.classList.add('clicked');
    // 300ms 后移除 clicked 态（短暂反馈）
    setTimeout(() => {
      this.classList.remove('clicked');
    }, 300);

    const promptText = this.getAttribute('data-prompt');
    // ... 后续回填逻辑不变
  });
});
```

## 三、完整变更清单（对 Codex 说）

### CSS 需修改的部分：

1. `.suggestion-card` — 增加 `position: relative`，过渡改为 `all 0.2s cubic-bezier(0.4, 0, 0.2, 1)`，padding 改为 `14px`
2. `.suggestion-card::before` — 新增伪元素，负责 hover 时的淡蓝背景光
3. `.suggestion-card:hover` — 增加 `transform: translateX(4px)`，边框改为 `primary-300`
4. `.suggestion-card:hover::before` — `opacity: 1`
5. `.suggestion-card:hover .card-title` — 颜色改为 `primary-600`
6. `.suggestion-card:hover .card-tag` — 颜色改为 `primary-500`
7. `.suggestion-card.clicked` — 新增类，点击后的短暂态
8. `@keyframes inputGlowPulse` — 新增输入框脉冲发光动画
9. `.input-box.input-glow-active` — 新增触发发光的类

### HTML 需修改的部分：

1. 为 6 个 `.suggestion-card` 增加 `data-prompt="..."` 属性，内容是每行对应的标准提示词模板

### JS 需新增的部分：

1. 在 `</body>` 前插入 `<script>` 块
2. 监听所有 `.suggestion-card` 的 click 事件
3. 点击时：给当前行加 `.clicked` → 读取 `data-prompt` → 填入 `.input-field` → `.input-field.focus()` → 给 `.input-box` 加 `.input-glow-active` → 光标移到末尾

## 四、设计规范引用（WeDesign Token）

| Token | 值 | 用途 |
|-------|-----|------|
| `--primary-50` | #eff6ff | hover 背景光 |
| `--primary-100` | #dbeafe | clicked 态背景 |
| `--primary-200` | #bfdbfe | 旧 hover 边框 |
| `--primary-300` | #93c5fd | 新 hover 边框（更醒目） |
| `--primary-400` | #60a5fa | 脉冲发光起始色 |
| `--primary-500` | #3b82f6 | 品牌蓝/脉冲峰值 |
| `--primary-600` | #2563eb | hover 标题文字色 |
| `--primary-700` | #1d4ed8 | clicked 标题文字色 |
| `--radius-md` | 8px | 卡片圆角 |
| `--spacing-md` | 16px | 卡片内边距 |
| `--spacing-lg` | 24px | 标题与标签间距 |

## 五、视觉预期

- **Hover 前**：纯文字行，无背景，透明边框
- **Hover 时**：整行右移 4px，出现淡蓝背景光，标题变深蓝，副标题变浅蓝，边框发浅蓝光
- **点击瞬间**：背景变深一点的蓝色，右移增至 6px，文字颜色加深，给用户一个「被按下去」的反馈
- **300ms 后**：行态恢复 hover 态，同时底部输入框出现一圈从中心向外扩散的蓝色脉冲光，输入框边框变蓝，告诉用户「文本已填入」
- **800ms 后**：脉冲光消失，输入框保持正常聚焦态，光标在文本末尾闪烁
